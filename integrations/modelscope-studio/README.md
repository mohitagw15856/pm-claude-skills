# PM Skills 技能试用 · PM Skills playground

[PM Skills](https://github.com/mohitagw15856/pm-claude-skills) 开源技能库的在线试用。选择一个技能，填入你自己的模型 API Key（DeepSeek、通义千问、Kimi、智谱 GLM、豆包，或 Claude、OpenAI、Gemini），即可运行。Key 只保存在你的浏览器里，请求直接发给模型服务商。

The playground for the open-source PM Skills library, mirrored to ModelScope. Bring your own model key; it stays in your browser.

- 源码 Source: <https://github.com/mohitagw15856/pm-claude-skills>
- Gitee 镜像: <https://gitee.com/mohitagw/pm-claude-skills>
- 数据集 Dataset: <https://www.modelscope.ai/datasets/mohitagw15856/pm-skills-instruct>

This Studio is published automatically from the repository's `web/` folder by `.github/workflows/publish-modelscope-studio.yml`. Do not edit files here; change them in the repository.
