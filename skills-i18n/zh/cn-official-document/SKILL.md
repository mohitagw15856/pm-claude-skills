# 公文

党政机关、事业单位和国有企业的公文有国家标准：文种依据《党政机关公文处理工作条例》（2012），格式依据 GB/T 9704-2012《党政机关公文格式》。文种用错、要素缺失，或者一份请示里请示了两件事，读者在看内容之前就会注意到。这个技能选对文种，用规范的语体起草正文，并按标准排版。

用简体中文写。单位自己的规定（有的部委和企业有补充要求）优先于这里的默认做法。

## 所需输入

如未提供，请询问：
- **目的**：这份公文要达成什么，由谁发给谁（上级、平级还是下级）
- **事实**：事项、日期、数字，以及请求的决定
- **发文机关**及其发文字号前缀（如已知）
- **附件**，以及抄送单位
- **单位模板**（如有）

## 输出结构

### 1. 文种判断
说明选用的文种及理由，从 15 种中选择：决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。指出常见混淆：请求批准用请示，不用报告；没有隶属关系的单位之间用函；通告面向社会，通知面向具体单位。

### 2. 按要素顺序排列的公文
缺少的事实用占位符：
- 版头：份号和密级（如需要）、紧急程度、发文机关标志、发文字号（例如〔2026〕12号，用六角括号）、上行文的签发人
- 主体：标题（发文机关 + 事由 + 文种）、主送机关、正文、附件说明、发文机关署名、成文日期（用阿拉伯数字，如 2026年10月4日）、印章位置、附注
- 版记：抄送机关、印发机关和印发日期
正文层级用四级序号：一、→（一）→ 1. →（1）。

### 3. 排版参数
给 Word 或 WPS 的参数表：A4 纸；标题 2号小标宋体；正文 3号仿宋；一级标题 3号黑体，二级标题 3号楷体；每面约 22 行、每行 28 字；页码用 4号半角宋体阿拉伯数字，两侧加一字线。

### 4. 文种规则检查
| 规则 | 通过或修改 |
|---|---|
| 请示：一文一事，只有一个主送机关，结尾为"妥否，请批示"等请求语 | |
| 报告：不夹带请示事项 | |
| 函：对平级单位语气得体，结尾酌用"请予支持"或"特此函告" | |
| 通知：写明谁在什么时间前做什么 | |
| 纪要：记录决定和负责人，而不是逐字记录 | |

## 质量检查

- [ ] 文种属于 15 种之一，并与发文双方的关系相符
- [ ] 每个必备要素都按 GB/T 9704 的顺序出现，或标明不适用
- [ ] 层级序号只用一、（一）1.（1）
- [ ] 成文日期用阿拉伯数字，发文字号用〔〕
- [ ] 请示只有一个请求事项，报告不含请求事项
- [ ] 没有出现用户未提供的事实、数字或人名

## 反模式

- **报告里请求批准。** 不会被当作请示答复；应写请示。
- **一份请示请示多件事。** 拆开，否则批复只会回应其中一件。
- **口语化表达。** 公文有固定的开头和结尾，随意的措辞显得不严谨。
- **编造发文字号。** 留占位符；文号由发文单位登记。

## 示例触发语

- “帮我写一份请示，申请增加两个编制。”
- “这份通知的格式对吗？按 GB/T 9704 检查一下。”
- “写一份给兄弟单位的函，商请协助调研。”
- “帮我为国有企业起草一份内部通知。”
