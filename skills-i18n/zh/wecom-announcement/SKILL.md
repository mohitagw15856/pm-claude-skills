# 企业微信公告

中国公司的内部通知通常在手机上、在拥挤的消息流里被阅读，读者两秒钟内就会判断这跟自己有没有关系。好的通知第一行就说清楚对象和要做的事，下面给细节，并写明联系人。这个技能为企业微信的公告功能、群聊和置顶消息写通知。

除非另有要求，用简体中文写。面向客户而不是员工的通知，见 `customer-outage-notice`。

## 产出内容

- **完整公告**：标题、要点、详细说明、需要你做的事、时间节点、联系人
- **群消息版本**：三到五行
- **置顶版本**：一行
- **提醒消息**：有行动要求时，在截止前发送

## 所需输入

如未提供，请询问：
- **发生了什么**、什么时间、为什么（可以告诉员工的原因）
- **影响谁**：全员、某些部门、某些地点或岗位
- **员工需要做什么**、何时之前（如有）
- **联系人**：负责答疑的人、团队或服务台
- **发布方和语气**：人力、IT、行政或管理层；常规还是敏感

## 方法

1. **标题写清事项和对象。** "【系统维护】10月12日 22:00 至 24:00 OA 系统暂停使用"比"关于系统维护的通知"好。
2. **要点一行**：要做的事和截止时间，不需要操作时写"无需操作"。
3. **按人群写细节。** 不同人群要做不同的事时，各给一个短段落。
4. **日期时间准确。** 写星期、日期、时间，跨地区办公时写时区。放假通知要逐一列出放假日期和调休上班日。
5. **礼貌、平实的语气。** 自然地使用"请"和"感谢理解与配合"；避免"为进一步加强……工作"之类的套话。
6. **敏感通知**（组织调整、政策收紧）：先说变化和生效日期，再说原因，最后说在哪里提问。不要超出发布方已确认的内容去推测。

## 输出格式

```
标题：【类别】[事项]（[时间]）

要点：[谁][需要做什么 / 无需操作]，[截止时间]

一、详细说明
[事项、原因、影响范围]

二、需要你做的事
1. [行动]，[截止时间]

三、时间安排
| 时间 | 事项 |

如有疑问，请联系：[联系人 / 部门 / 方式]

[发布部门]
[日期]
```

然后给出**群消息版本**、**置顶版本**，有行动要求时再给**提醒消息**（截止前一天发送）。

## 质量检查

- [ ] 标题写明了类别、事项和时间
- [ ] 第一行说明了员工要做什么，或无需操作
- [ ] 每个日期都有星期，每个时间段都有开始和结束
- [ ] 放假通知逐一列出了调休上班日
- [ ] 写明了具体联系人
- [ ] 没有把发布方未确认的内容写成事实

## 反模式

- **重要的话放在第四段。** 大多数人读不到那里。
- **"关于……的通知"式标题。** 把内容藏起来了。
- **漏写调休日。** 这是放假通知后被追问最多的原因。
- **在敏感通知里透露未确认的细节。** 说清已经决定的内容，以及什么时候会有更多信息。

## 示例触发语

- "帮我写一则国庆放假通知，有两个调休日。"
- "写企业微信公告：周六晚上 OA 系统维护。"
- "写一则关于办公室搬迁的中文员工公告。"
- "部门架构调整，帮我写一则内部公告，语气要稳。"
