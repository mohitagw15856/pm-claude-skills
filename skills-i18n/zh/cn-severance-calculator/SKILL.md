# 经济补偿金估算

在中国大陆，劳动关系结束时应得多少钱，取决于怎么结束、工作了多久、收入多少以及所在城市。很多人因为不知道适用哪种情形、封顶怎么算，接受了比应得更少的补偿。这个技能判断可能适用的情形，写出计算过程，并列出签署解除协议前要核对的事项。

除非用户另有要求，用简体中文输出。中国以外的离职协议解读请使用 `severance-agreement-decoder`。

## 这个技能产出什么

- **可能适用的情形**：N、N+1 或 2N，附条款依据和所依赖的事实
- **逐步计算**：折算年限、月工资基数、封顶检查、合计
- **签字前清单**：可能还应得的其他款项（未休年假、未付工资、奖金、社保）
- **去哪里确认**：当地劳动人事争议仲裁委员会或劳动法律师

## 所需输入

如未提供，请询问：
- **入职日期和最后工作日**
- **过去 12 个月的平均月工资**（税前，包括固定发放的奖金和津贴）
- **劳动关系如何结束**：谁提出的、给出的理由、是否提前 30 天书面通知
- **工作地所在城市**，收入较高时还需要当地公布的职工月平均工资
- **被要求签署的协议**（如有）

## 框架：适用哪种情形

| 结束方式 | 通常 | 条款 |
|---|---|---|
| 用人单位提出，双方协商一致解除 | N | 第 36、46 条 |
| 用人单位因不能胜任或客观情况发生重大变化解除（第 40 条），提前 30 天通知 | N | 第 40、46 条 |
| 同上，未提前 30 天通知 | N + 1 | 第 40 条 |
| 经济性裁员（第 41 条） | N | 第 41、46 条 |
| 固定期限合同到期，用人单位不续签，或以更差条件续签而员工拒绝 | N | 第 46 条 |
| 因用人单位未履行义务（拖欠工资、不缴社保）而员工解除 | N | 第 38、46 条 |
| 用人单位违法解除 | 2N | 第 48、87 条 |
| 员工因个人原因辞职 | 通常没有 | |

计算方法（第 47 条）：
- **年限**：每满一年支付一个月工资。六个月以上不满一年的，按一年计算；不满六个月的，支付半个月工资。
- **月工资基数**：劳动关系结束前 12 个月的平均工资。
- **封顶**：月工资高于当地职工月平均工资三倍的，基数按三倍计算，年限最多 12 年。
- **+1**：一个月工资作为代通知金。用哪个月的工资，各地做法不同。

需要提示的情况：
- 2008 年 1 月 1 日之前的工作年限，可能按当时的规定计算。
- 孕期、产期、哺乳期、职业病、医疗期以及部分长期服务的情形受法律特别保护；如有，解除本身可能违法。
- 经济补偿金与未付工资、未休年假工资、已经产生的奖金是分开的。

## 输出格式

### 经济补偿金估算：[姓名]

**一、适用情形**：[N / N+1 / 2N]，依据 [条款]，因为 [事实]。如有不确定的事实，列出。

**二、计算过程**
| 项目 | 数值 | 说明 |
| 工作年限 | ... | 起止日期，折算规则 |
| 月工资基数 | ... | 12 个月平均；是否封顶 |
| N | ... | |
| +1 / ×2 | ... | |
| 合计 | ... | |

**三、签字前请确认**
- 未付工资、未休年假工资、已发生的奖金、社保公积金缴纳情况
- 协议中是否有放弃其他权利的条款

**四、去哪里确认**：当地劳动人事争议仲裁委员会，或劳动法律师

结尾原文写明：*"以上为估算，不构成法律意见。各地规定和裁判口径不同，签署任何协议前请向当地劳动仲裁机构或劳动法律师确认。"*

## 质量检查
- [ ] 情形对应到条款和用户给出的事实
- [ ] 折算年限遵循六个月规则，最后工作日计入
- [ ] 知道当地平均工资时检查封顶，不知道时提示
- [ ] 其他应得款项与经济补偿金分开列出
- [ ] 结尾声明原文出现

## 反模式
- **默认就是 N+1。** +1 只适用于一种具体情形。
- **只用基本工资**，而奖金和津贴本属于工资的一部分。
- **跳过特殊保护期的检查。** 它可能让 N 变成 2N。
- **建议用户签字。** 只做计算、列出核对事项、指明去哪里确认。
