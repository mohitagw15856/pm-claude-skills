# 薪资谈判

大多数人少拿了钱，是因为他们带着焦虑而不是准备去谈。这个技能用计划代替紧张：按**总薪酬**（而不只是基本工资）比较 offer，以 BATNA 为锚设定目标价和底线，用你的价值来支撑要价，并写好还价话术，包括基本工资之外那些往往更容易谈成的项目。

## 所需输入

仅在尚未提供时询问：

- **offer**：基本工资、奖金、股权、签约奖金和其他组成部分（以及竞争 offer，如有）。
- **你的处境**：当前薪酬、你的 BATNA（最佳替代方案，例如另一个 offer 或留在现职），以及双方各自有多需要对方。
- **市场数据**：该岗位、职级、地点的可比薪资范围（levels.fyi、Glassdoor、同行），如有。
- **你在意什么**：现金还是股权增值、灵活性、职位、入职日期。

## 输出格式

### 谈判计划：[公司] 的 [岗位]

**1. 总薪酬比较**：绝不只比基本工资。列出各 offer 和你当前（或替代方案）的年度总薪酬（用辅助脚本）。股权和奖金常常会改变排序。

**2. 你的数字**：**目标价**（有野心但站得住）、**底线**（低于此就拒绝）和**锚点**（开价略高于目标价）。三者都以市场和你的 BATNA 为锚。

**3. 筹码判断**：你有多少筹码（竞争 offer？稀缺技能？对方在流程上已经投入很多？），以及如何使用而不虚张声势。

**4. 理由**：基于价值的要价理由：你的证据（影响、可比薪酬、竞争 offer），用合作的方式表达（"我很期待加入；为了让这件事成……"）。

**5. 还价话术**：以下情况的具体措辞：还价基本工资、回应"这已经是我们的上限"，以及**基本工资之外的筹码**（签约奖金、股权、职位或职级、入职日期、远程、调薪评估时间），在基本工资谈不动时这些往往能谈。

**6. 底线计划**：如果对方达不到你的底线，你会怎么做（以及为什么提前决定这件事才是你真正的力量）。

## 程序辅助

`scripts/comp_compare.py`（只用标准库）计算各 offer 的年度总薪酬，让比较口径一致（股权按年摊销，签约奖金按年折算）：

```bash
# offers.json: [{"name":"Offer A","base":160000,"bonus":24000,"equity_total":200000,"equity_years":4,"signing":20000}, ...]
python3 scripts/comp_compare.py offers.json
python3 scripts/comp_compare.py offers.json --signing-years 1 --json
```

## 质量检查

- [ ] 按**总薪酬**比较 offer，而不只是基本工资（包括股权、奖金、签约奖金）
- [ ] 设定了目标价、底线和锚点，并与市场和 BATNA 挂钩
- [ ] 理由基于价值、有证据，而不是"我需要更多"
- [ ] 包含基本工资之外的筹码（签约奖金、股权、职位、入职日期、远程）
- [ ] 底线在谈话*之前*就已决定

## 反模式

- [ ] 不要只比基本工资：总薪酬才是真实的数字，股权和奖金常常改变哪个 offer 更好
- [ ] 不要在没有提前决定底线的情况下谈判：底线是你筹码的来源
- [ ] 不要虚构一个并不存在的竞争 offer：一旦被追问，你会失去全部信誉
- [ ] 不要开价过低或接受第一个数字：第一个 offer 几乎总有空间
- [ ] 不要只盯着基本工资：基本工资封顶时，签约奖金、股权、职级和入职日期常常可以谈

## 依据

原则谈判法（*Getting to Yes*，Fisher 与 Ury：BATNA、关注利益而非立场）在薪酬谈判中的应用。
