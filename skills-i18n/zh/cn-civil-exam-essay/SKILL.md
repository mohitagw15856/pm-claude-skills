# 申论

申论是公务员考试的笔试科目。它不是自由写作：考生阅读给定资料并作答，分数主要来自从资料中找出并组织好正确的要点。考生失分通常是因为写了资料不支持的观点、漏了要点，或者超出字数。这个技能用真实的练习题教方法，并按要点批改答案。

用简体中文写。本技能是学习辅助工具，不预测考题，也不保证分数；以考试主管部门的官方材料为准。

## 产出内容

- **题型判断**：属于哪种常见题型，这类题看重什么
- **资料要点**：每个要点及其所在段落
- **参考答案**：符合格式要求，不超字数
- **批改用户的答案**：答到、漏掉和无依据的要点，以及大致档次
- **练习计划**：针对薄弱题型

## 所需输入

如未提供，请询问：
- **题目**及其**字数要求**
- **给定资料**，或相关段落
- **用户自己的答案**（如需批改）
- **考试级别**：国考（副省级或地市级）还是省考，侧重点不同
- **距离考试的时间**，用于制定练习计划

## 方法

1. **判断题型。** 常见题型有归纳概括、综合分析（分析观点、现象或词句）、提出对策、贯彻执行（讲话稿、通知、报告等应用文）和文章写作（大作文）。每种题型有自己的结构。
2. **审题看限定。** 谁写、写给谁、写什么、多少字。贯彻执行题会指定文种，格式本身就是得分点。
3. **提取要点。** 逐段阅读，摘出回答问题的语句，合并重复，资料原话准确的就保留原话。每个要点注明出处段落。
4. **先组织，再写作。** 用清楚的小标题或序号归类要点。大作文：明确的总论点，三个来自资料的分论点，论据，以及回扣总论点的结尾。
5. **按要点批改。** 按要点数量、表述准确度、结构和语言打分；无依据的观点和超字数要扣分。

## 输出格式

### 题型判断
[题型]：这类题主要考查 [...]，答题结构是 [...]

### 要点提取
| 序号 | 要点 | 来源（资料第几段） |

### 参考答案（[字数] 字以内）
[答案]

### 批改（如提供了作答）
| 要点 | 是否答到 | 说明 |
- 无依据的观点：[...]
- 字数：[实际字数] / [限制]
- 大致档次：一类 / 二类 / 三类 / 四类，理由：[...]

### 练习建议
[薄弱题型、每周练习安排、复盘方法]

## 质量检查

- [ ] 写明了题型及其答题结构
- [ ] 每个要点都注明了来自资料的哪一段
- [ ] 参考答案没有超出字数
- [ ] 参考答案中的每个要点都有资料支持
- [ ] 贯彻执行题遵循了指定文种的格式
- [ ] 档次标注为大致估计

## 反模式

- **凭常识作答。** 分数来自资料。
- **整句照抄。** 要提炼压缩，长段引用浪费字数。
- **忽略写作者身份。** 街道干部的讲话稿和给领导的报告写法不同。
- **承诺分数。** 各考试、各年份的评分标准不同。

## 示例触发语

- "帮我批改这道申论归纳概括题，资料和我的答案都在这里。"
- "申论大作文怎么搭框架？用这份资料练一篇。"
- "这道贯彻执行题要写倡议书，格式是什么？"
- "帮我练习国考申论。"
