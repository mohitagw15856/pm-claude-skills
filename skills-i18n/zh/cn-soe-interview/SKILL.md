# 国企面试

国企和央企每年招聘大量应届生和社招人员，流程和民营科技公司不同：笔试常包含行测类题目和对企业及行业的了解，面试看重稳定性、团队合作和与组织的匹配，发 offer 前通常有背景调查。这个技能为每个环节做准备，并帮助把 offer 与民营企业的选择作比较。

除非另有要求，用简体中文写。各企业、各地区的流程和内容差别很大；以招聘公告为准。

## 产出内容

- **流程图**：报名、笔试、面试、体检、背调和录用，标注需对照公告确认
- **笔试计划**：行测类题目、专业知识，以及企业业务和近期新闻
- **问题库**及回答要点：自我介绍、求职动机、稳定性、团队合作、专业问题和情景题
- **模拟面试**：一次一题，附反馈
- **Offer 对比**：按用户看重的维度与民营企业选择比较

## 所需输入

如未提供，请询问：
- **企业、岗位和招聘公告**，或公告摘要
- **背景**：学历、专业、经历，以及岗位要求的证书
- **面试形式**（如已知）：结构化面试、半结构化、无领导小组讨论或专业面试
- **正在考虑的其他 offer 或选择**

## 方法

1. **仔细阅读公告。** 报名条件（年龄、学历、专业、证书）、工作地点和服务期要求。这里不符合，面试再好也没用。
2. **了解企业。** 主营业务、在行业中的位置、近期重大项目，以及公开报告中使用的战略表述。面试官希望考生知道企业是做什么的。
3. **准备笔试。** 限时练习行测、岗位列出的专业知识，以及与行业相关的时事。
4. **回答体现匹配。** 常见问题："为什么选择国企 / 我们公司？"、"能否接受外派或基层锻炼？"、"你的职业规划是什么？"、"和同事意见不合怎么办？"、"你在团队中通常是什么角色？"。好的回答真诚、具体，并表明考生思考过岗位的真实条件。
5. **提好的问题。** 关于培训、轮岗、第一年的工作内容和绩效考核方式。
6. **诚实比较。** 权衡稳定性、薪酬结构、地点、成长速度、工作本身和个人目标；没有适合所有人的选择。

## 质量检查

- [ ] 每个环节都标注了需对照招聘公告确认
- [ ] 已对照用户背景检查报名条件
- [ ] 问题库包含动机、稳定性、团队合作和专业问题
- [ ] 回答要点使用企业的真实业务，而不是泛泛的称赞
- [ ] 反馈对每个维度给出具体改进建议
- [ ] Offer 对比使用用户自己的优先级

## 反模式

- **只谈稳定。** 面试官想看到对工作的投入，而不只是对安稳的追求。
- **不了解业务。** 这是原本不错的面试最常见的失败原因。
- **过度承诺**用户其实不能接受的外派或轮岗。
- **把选择当成显而易见。** 国企和民企适合不同的目标。

- “国企 offer 和互联网 offer 怎么选？”
- “帮我准备国企面试。”
