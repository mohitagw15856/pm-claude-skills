# 求职信

大多数求职信都是读者会跳过的客套话。好的求职信只做一件事：用像真人说话的语气，把*你的具体证据*和*这家公司的具体需要*连接起来。这个技能写一封紧凑、定制的信，没有"我写信是为了申请……"，也不复述简历，让人愿意读完。

## 所需输入

仅在尚未提供时询问：

- **岗位和公司**，以及职位描述（信必须针对它来写）。
- **为什么是这家公司**：真实的理由，例如对方的产品、使命、最近的动作（避免空泛的恭维）。
- **你最有力、最相关的两到三个证据**：能对应到对方需求的成就。
- **语气**：温和专业（默认），或按公司文化更正式或更有创意。

## 输出格式

一封三到四段的信（英文约 250 到 350 词，中文约 400 到 600 字）：

> [姓名] · [邮箱] · [电话] · [日期]
> 尊敬的 [招聘经理姓名，不知道时写"招聘团队"]：

**开头钩子（一小段）**：开门见山写出你写信给*他们*的具体理由，即与对方产品、使命或当下动向的真实联系，以及你想要的岗位。不要写"我写信是为了申请"。

**证据（一到两段）**：核心部分：挑出岗位最重要的两到三项需求，每项用一个具体结果说明你做过。把你的证据对应到他们的问题；不要复述简历，而是*解读*它。

**结尾（一小段）**：你能带来什么、真诚的热情，以及一句面向未来的话（"很希望能和您聊聊……"）。自信，而不是急切。

> 此致，[姓名]

**语气提示**（给用户）：保持像人说话：主动语态，不用生僻词。读出来；如果听起来像机器人，就删。

## 质量检查

- [ ] 开头针对这家公司，不能原样发给另一家雇主
- [ ] 每个证据点都把一个真实、有数字的结果对应到岗位明确的需求之一
- [ ] 它补充简历（解读和连接），而不是重复简历的要点
- [ ] 英文约 350 词以内；段落紧凑、易扫读
- [ ] 语气像真人，不像模板
- [ ] 能找到收信人姓名时写明姓名

## 反模式

- [ ] 不要以"我写信是为了申请……职位"开头：它浪费了最有价值的一行
- [ ] 不要复述简历：求职信增加的是联系和背景，而不是重复的清单
- [ ] 不要空泛恭维（"贵公司声誉卓著"）：写出真实、具体的东西
- [ ] 不要凑满一页：紧凑的四段胜过一整页填充
- [ ] 不要显得急切或傲慢：目标是自信和真诚的兴趣

## 依据

现代求职信写法：具体的开头钩子、证据对应需求、真人的语气。
