# 自评

自评是你在别人定义你这一年之前，自己定义它的唯一机会。写得不好，是一串含糊的活动清单；写得好，是一段有证据的叙述：把你的工作对应到考核的能力，诚实承认成长方向，并为下一级做铺垫。这个技能就写后者，如果你有 [`brag-doc`](../../../skills/brag-doc/SKILL.md)，可以直接从中取材。

## 所需输入

仅在尚未提供时询问：

- **你的岗位、职级和评估周期。**
- **成就**：带影响或数据的成绩（或指向你的 brag doc）。
- **考核所依据的能力框架或评分维度**（如有）。
- **成长方向**：做得不够或想要提升的地方（要诚实；评审者信任自我认知）。
- **下一周期的目标。**

## 输出格式

### 自评：[姓名]，[岗位]，[周期]

**1. 概述**：3 到 4 句话：这个周期的主线和标题。先写影响。

**2. 主要成就**：最重要的 3 到 6 项，每项写成**结果 → 你的贡献 → 证据 → 体现了哪项能力**。用数字量化；对应到团队或公司目标。

**3. 优势**：你最突出体现的 2 到 3 项能力，附证据。

**4. 成长方向**：1 到 3 项，坦白承认：什么很难、学到了什么、你在改变什么。当它具体且不带防御时，这一部分会*增加*可信度（不要写"我工作太拼了"）。

**5. 目标与发展计划**：下一周期的重点和需要的支持。

**6. 评级理由**（*如需自评打分*）：你给自己的评级和证据，对照评分标准：不夸大，也不假装谦虚。

## 质量检查

- [ ] 成就有数字，并对应到能力框架或公司目标
- [ ] 每个说法都有具体证据支撑，而不是形容词
- [ ] 成长方向真实、具体（不是变相夸自己），并写了正在怎么改
- [ ] 叙述有主线，而不只是清单
- [ ] 自评打分（如有）对照评分标准、有证据：站得住，而不是理想化

## 反模式

- [ ] 不要罗列活动：每项成就都对应到结果和能力
- [ ] 不要把优点伪装成缺点（"太注重细节"）：读起来像回避；写一个真实的成长方向
- [ ] 不要把团队的成绩说成个人的，也不要出于谦虚低估自己的角色：准确说明你的贡献
- [ ] 不要把自评打分抬到证据支撑不了的程度：在校准时会损失信誉
- [ ] 不要用含糊的最高级：没有数字，"带来了显著影响"毫无意义

## 依据

基于能力的绩效评估实践：对应证据的成就和经过校准的自我评估。
