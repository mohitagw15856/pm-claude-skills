# 押金追回

押金争议在退租那天就决定了胜负，比房东做任何决定都早好几周：有每面墙带时间戳照片、完成了交房检查、书面留下新地址的租客能拿回押金；只有记忆的租客只能去谈。这个技能覆盖两个阶段：还能进房时的证据流程，以及收到扣款后的质疑与升级阶梯。它围绕几乎决定每个争议的那条界线：正常损耗（房东的经营成本，在大多数地方不能扣）与损坏（你的责任）。

## 这个技能产出什么

- **退租流程**：照片和视频巡查、交房检查请求、清洁收据档案、新地址告知信
- **扣款质疑**：每项扣款分为损耗、损坏或无依据，并附回应
- **升级阶梯**：明细请求、催款信，以及期限计算（标注取决于当地法规）
- **小额诉讼准备清单**：金额值得时，要带什么，以及这类庭审实际上怎么进行

## 所需输入

如未提供，请询问：
- **所处阶段**：还住在房子里（执行证据流程，价值最高）、已搬出等待退还，还是已收到扣款明细（质疑阶段）
- **已有的书面材料**：租约中关于押金的条款、入住检查记录（如果没有，这本身就有用）、入住和退租时的照片、所有沟通记录
- **数字**：押金金额、被扣金额、退租后过了多久（退还期限因地而异，往往很短，时间可能已经是租客最有力的论点）
- **房东类型**：个人房东还是物业管理公司；阶梯的语气相同，但公司看流程，个人房东看具体细节

## 框架：损耗与损坏的规则

1. **具体划线：** 褪色的墙漆、轻微擦痕、地毯上走出来的痕迹、小钉孔属于损耗（时间造成的，通常不能扣）。污渍、烫痕、破洞、坏掉的设施、未经同意的刷漆属于损坏（某件事造成的）。填缝变暗是损耗；瓷砖开裂是损坏。每项扣款都按这条线归类，边界情况标注因地而异。
2. **损坏也要计算折旧：** 一块用了 8 年的地毯因为一处污渍报废，房东却按全新价格收费，等于让你为升级买单。按使用年限折算是标准的反驳，质疑信会用算术来说明。
3. **证据胜过形容词：** 退租巡查要系统：每个房间、每面墙、家电内部、各种表，带时间戳，并在手机以外备份。配对的入住照片（或房东本应提供却没有的入住检查记录）为之后的每个论点定下框架。
4. **程序是双刃剑：** 退还或列明细的期限、提供收据的要求、新地址规则，都因地而异，常常有利于租客，有时对恶意扣押还有加倍赔偿。信件引用这些规则的*类别*，并标注需在当地核实；已经错过的期限按经过的天数指出。
5. **按时间表升级，而不是按情绪升级：** (a) 书面要求提供扣款明细和收据；(b) 质疑信：逐项列出、附证据、写明要求的金额、给出期限、说明下一步；(c) 正式催款函，读起来就像它将成为的小额诉讼起诉状；(d) 小额诉讼：专为这类金额设计，通常不需要律师，准备清单基本就是已经建好的证据档案。

## 输出格式

# 押金追回：[金额]，阶段：[证据流程 / 等待退还 / 质疑扣款]

## [阶段一] 退租流程
[按房间的巡查清单 · 交房检查请求措辞 · 要保留的收据 · 注明日期的新地址告知信]

## 扣款质疑
| 被扣项目 | 金额 | 损耗 / 损坏 / 无依据 | 回应（适用时附折旧计算） |
|---|---|---|---|

## 升级阶梯
[每一级附完整信件、期限，以及时间已过时的经过天数 · 加倍赔偿类别标注需在当地核实]

## 小额诉讼准备（如果走到这一步）
[成本账（诉讼费与金额对比）· 证据册的顺序 · 庭审如何进行 · 常见的庭前和解]

> 押金期限、扣款规则和处罚条款因地而异；引用具体数字前请先核实当地规定；正因如此，这里的信件只引用规则类别。不构成法律意见。

## 质量检查

- [ ] 每项扣款都分为损耗、损坏或无依据，并附理由，而不是笼统处理
- [ ] 凡是对旧物按全新价收费的地方都附了折旧计算
- [ ] 信件的语气逐级加强，同时始终适合在法庭上阅读
- [ ] 因地而异的规则以标注的类别出现，绝不断言具体数字
- [ ] 小额诉讼部分包含真实的成本账，而不只是操作步骤

## 反模式

- [ ] 不要为了显得讲理而让步损耗项目：那条线就是整个争议
- [ ] 不要带着怒气写：每封信都是证据一号；让事实来表达分量
- [ ] 不要把具体法条或天数当作事实引用：只写类别，并标注需在当地核实
- [ ] 不要跳过要求明细这一级：很多扣款在第一次要求出示收据时就站不住了
- [ ] 不要让怒气决定是否起诉：准备清单的第一行就是算账

## 示例触发语

- “押金怎么要回来？”
- “房东扣着我的押金不退。”
- “对这些押金扣款提出异议。”
- “帮我写一封催退押金的信。”
