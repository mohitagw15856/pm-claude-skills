# 考研规划

考研是一个长期项目：大多数考生要边上学或边工作边准备好几个月，结果既取决于努力，也取决于是否选了现实的目标、做了能坚持的计划。这个技能帮助基于证据选择目标，为每门科目制定分阶段计划，并准备复试以及必要时的调剂。

用简体中文写。日期、科目和分数线每年都会变化：这里的每个日期和规则都要对照教育部研招平台和目标院校研究生院的官方通知确认。

## 产出内容

- **择校方法**：每个专业要收集的数据，以及如何比较录取机会
- **分阶段复习计划**：按科目分为基础、强化、冲刺和最后复习
- **每周模板**：符合用户可用的时间
- **关键时间清单**（报名、确认、初试、出分、复试、调剂），标注"以官方通知为准"
- **复试和调剂指南**：面试准备、英语口语、专业问题，以及调剂思路

## 所需输入

如未提供，请询问：
- **现状**：在校年级还是在职，本科学校和专业，成绩，英语水平
- **目标方向**，学硕还是专硕，以及已有的目标院校
- **考试科目**：政治、英语（一或二）、数学（一、二、三）或专业基础，以及专业课
- **可用时间**：工作日和周末每天几小时，距离考试几个月
- **风险偏好**：冲刺、求稳还是保底

## 方法

1. **基于证据择校。** 每个候选专业收集：招生人数、公布的报考人数、往年复试线和录取分数、专业课考试大纲和参考书、推免比例。列出一个冲刺、两个稳妥、一个保底的选项。
2. **全年分阶段。** 基础（每个知识点都理解）、强化（分专题练习）、冲刺（限时做真题）、最后复习（错题、背诵、模拟考）。政治通常比数学和英语开始得晚；专业课按目标院校的大纲来。
3. **计划落到每周。** 在状态最好的时段固定安排最难的科目，每天英语单词和阅读，每周一次模拟或真题，每周复盘错题本。
4. **保护计划。** 每周留一天轻松日，每月留一周缓冲。不考虑现实生活的计划会被放弃。
5. **尽早准备复试。** 专业知识、中英文简短自我介绍、与学校导师方向相关的研究兴趣、项目经历记录。如果成绩不理想，准备调剂：关注官方调剂公告，及时申请，用同样的证据比较专业。

## 质量检查

- [ ] 每个目标专业的证据列都已填写，或标注为未知
- [ ] 择校包含冲刺、稳妥和保底选项
- [ ] 计划中的每周时长不超过用户说的可用时间
- [ ] 每个日期都标注"以官方通知为准"，没有写成确定的
- [ ] 计划包含每周错题复盘和缓冲时间
- [ ] 复试准备在初试出分前就开始

## 反模式

- **只看学校名气。** 分数线、招生人数和推免比例决定机会。
- **每个小时都排满的计划。** 第一个忙碌的星期就会崩掉。
- **政治和英语听天由命。** 公共课有单科线。
- **等出分再想复试。** 有实力的考生会同步准备。

## 示例触发语

- “我大三，想考计算机专硕，帮我做一年的考研计划。”

- “在职考研，每天只有三个小时，计划怎么排？”
- “帮我规划经济学硕士的考研复习。”
