# 大厂技术面试

国内互联网公司的技术面试有固定的套路：在线笔试，两到三轮技术面（八股、手撕算法、系统设计、项目深挖），然后是 HR 面。面试官会对每个回答不断追问，直到摸到候选人真实掌握的边界。这个技能为目标岗位制定准备计划，并用同样的方式进行模拟面试。

除非另有要求，用简体中文写。各公司流程会变化，轮次请向招聘方确认。

## 所需输入

如未提供，请询问：
- **目标岗位和级别**：后端、前端、客户端、算法、测试、数据；校招还是社招
- **技术栈**：例如 Java、Go、C++、Python、JavaScript 和 React 或 Vue
- **简历上的项目**，以及自己的角色和数据
- **面试日期**和每天可用的时间
- **薄弱环节**（如已知）

## 输出结构

### 1. 轮次与计划
| 轮次 | 考查什么 | 准备内容 | 天数 |
覆盖笔试（限时算法）、一面（基础和编码）、二面（项目和设计）、交叉面或主管面（深度和判断）、HR 面（动机、期望）。

### 2. 按技术栈的八股题库
分组整理，每题附回答要点和可能的追问。例如：
- 计算机网络：TCP 三次握手与四次挥手（追问：为什么是三次？TIME_WAIT 的作用？）；HTTP/1.1、HTTP/2、HTTP/3 的区别；HTTPS 握手
- 操作系统：进程与线程；虚拟内存；I/O 多路复用（select / poll / epoll）
- 数据库：MySQL 索引（B+ 树、最左前缀、回表）；事务隔离级别与 MVCC；慢查询排查
- Redis：数据结构；持久化（RDB / AOF）；缓存穿透、击穿、雪崩
- 技术栈专项：Java（JVM 内存模型、GC、并发包、Spring）、Go（GMP 调度、channel）、前端（事件循环、浏览器渲染、React 或 Vue 原理）

### 3. 算法
按优先级的专题清单（数组与双指针、哈希、链表、二叉树、回溯、动态规划、图），每个专题三道代表题，以及面试官看重的习惯：先澄清输入、说明复杂度、出声测试边界情况。

### 4. 系统设计示例
按岗位选一个完整示例（秒杀系统、短链服务、Feed 流、分布式 ID），用固定框架：需求与规模估算、API、数据模型、核心设计、瓶颈、取舍。

### 5. 项目深挖
每个简历项目：30 秒概述、最难的问题和自己的决策、数据、如果重做会改什么，以及面试官会问的五个追问。

### 6. 模拟面试
一次一题。每个回答之后：追问直到找到边界，然后从正确性、深度和表达三方面打分（1 到 5），并指出遗漏的要点。

## 质量检查

- [ ] 计划覆盖目标公司的每一轮，并分配了天数
- [ ] 每道八股题都有回答要点和至少一个追问
- [ ] 系统设计示例写明了规模估算和取舍
- [ ] 每个项目话术都写明了自己的决策和一个数据
- [ ] 模拟面试一次只问一题，先追问再打分
- [ ] 没有把任何公司的内部题库说成泄露或官方的

## 反模式

- **只背不懂。** 两次追问就会露馅。
- **项目深挖时说"我们做了"。** 面试官想听你自己的决策。
- **闷头写代码。** 要边想边说，表达也计分。
- **没有数字的设计。** 没有规模估算的设计无法评判。

## 示例触发语

- "下周字节后端一面，帮我模拟一轮。"
- "Java 八股文按优先级帮我列一下，附追问。"
- "帮我准备项目深挖，项目是一个订单系统。"
- "模拟一场大厂前端技术面试。"
