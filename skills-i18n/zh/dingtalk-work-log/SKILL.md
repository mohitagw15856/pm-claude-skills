# 钉钉日志

很多中国公司用钉钉办公，钉钉的日志功能要求员工按固定字段提交日报、周报或月报。字段很小，通常在手机上填写，所以好的日志要简短、具体，并且如实写出没完成的事。这个技能把零散笔记整理成每个字段的内容。

除非另有要求，用简体中文写。如果要写钉钉以外的长篇周报，见 `cn-weekly-report`。

## 产出内容

- **逐字段的日志**，对应钉钉默认模板：
  - 日报：今日完成工作 / 未完成工作 / 需协调工作 / 备注
  - 周报：本周完成工作 / 本周工作总结 / 下周工作计划 / 需协调与帮助
  - 月报：本月工作内容 / 本月工作总结 / 下月工作计划 / 需帮助与支持
- **一句话版本**，用于团队群消息
- **顺延说明**：昨天未完成、今天仍未完成的事项

## 所需输入

如未提供，请询问：
- **日志类型**：日报、周报还是月报
- **笔记**：做了什么，任何形式都可以
- **昨天或上一期的日志**（如有），用于跟踪顺延事项
- **公司自定义的模板字段**（如与默认不同），按公司的来

## 方法

1. **一项一行。** 每一项以动词开头，以结果或状态结尾："完成订单导出接口联调，已提测"，而不是"订单导出"。
2. **有数字就写数字。** 数量、百分比、工单号。不要编造。
3. **未完成要如实。** 每个未完成项写明原因和新的完成时间："支付回调测试未完成：测试环境证书过期，已找运维，预计明天上午完成"。
4. **需协调要点名。** 写明需要哪个人或团队、做什么、何时之前。字段为空可以，含糊不行。
5. **周报和月报要有判断。** 工作总结用两三行写做得好的、没做好的和接下来要改的，而不是把清单再列一遍。
6. **适配手机。** 每个字段大约五行以内，细节可以放在文档链接里。

## 输出格式

```
【今日完成工作】
1. [动词 + 事项 + 结果 / 状态]
2. ...

【未完成工作】
1. [事项]：[原因]，[新的完成时间]

【需协调工作】
1. [需要谁] [做什么] [何时之前]

【备注】
[可选：链接、明日重点]
```

**群消息版本**：[一句话：今天最重要的结果 + 需要的协调]

周报和月报使用上面列出的对应字段名，工作总结写两三行反思。

## 质量检查

- [ ] 每个完成项都以动词开头，写明结果或状态
- [ ] 每个未完成项都有原因和新的时间
- [ ] 每个协调请求都写明谁、做什么、何时之前
- [ ] 从上一期顺延的事项已标注（顺延）
- [ ] 没有出现用户未提供的数字、工单号或人名
- [ ] 每个字段大约五行以内

## 反模式

- **"正常推进中"。** 什么都没说。写状态或下一步。
- **照抄昨天的日志。** 上级看得出来。顺延要标注，不要悄悄重复。
- **把阻碍藏在备注里。** 阻碍应该写在未完成或需协调里，才会被看到。
- **凑字数。** 简短如实的日志比塞满日常琐事的长日志更好。

## 示例触发语

- “帮我写今天的钉钉日报，笔记在这里。”
- “钉钉周报怎么写？帮我把这周的事整理一下。”
- “根据这些笔记填一下我的钉钉日报。”
- “写月报，下个月的计划要具体一点。”
