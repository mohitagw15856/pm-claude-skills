## 사용 방법

다른 스킬과 같습니다. 폴더를 `~/.claude/skills/`에 복사하거나(Claude Code), ChatGPT나 Gemini에 지침으로 붙여 넣거나, [무료 플레이그라운드](https://mohitagw15856.github.io/pm-claude-skills/)에서 영어판을 열어 사용합니다. 한국어로 요청하면 결과도 한국어로 받을 수 있습니다.
