# 경쟁사 분석 스킬

이 스킬은 전략 자료, 투자자 자료, 영업 지원, 제품 기획 회의에 쓸 수 있도록 구조화된 완전한 경쟁 분석 문서를 만든다.

## 필요한 입력

주어진 것으로 작업한다. 아래 중 빠진 것이 있어도 전체 결과물을 만든다. 빈 곳은 *(가정, 확인 필요)*로 표시한 합리적인 가정으로 채우고, 그 가정들을 마지막에 나열한다. 핵심 주제 자체가 없을 때(쓸 내용이 아무것도 없을 때)만 먼저 질문한다.
- **자사 제품** (이름 + 한 줄 설명)
- **분석할 경쟁사** (2~5곳의 이름. 주어지지 않았다면 물어본다)
- **분석 깊이** (간단한 개요 / 상세 분석)
- **이 분석의 주된 용도** (예: 영업 지원, 투자자 자료, 내부 전략, 제품 기획)

## 심화 자료

- **`references/intel-sourcing-guide.md`**: 경쟁 정보의 출처(네 가지 출처 등급), 분석 섹션별로 쓸 출처, [verified]/[reported]/[assumed] 신뢰도 표시, 그리고 윤리 기준. 결과물의 모든 실질적인 주장에 이 표시를 적용한다.
- **`templates/teardown-skeleton.md`**: 신뢰도 표시와 검증 대기 목록이 들어 있는 빈칸 채우기용 분석 양식. 사용자가 정보를 직접 수집하고 싶어 할 때 제안한다.

## 출력 구성

### 1. 경쟁 구도 개요

시장의 역학을 요약한 한 문단: 주요 업체가 누구인지, 시장이 어떻게 나뉘는지, 빈 공간이 어디에 있는지. 150단어 이내로 쓴다. 이것이 경영진용 요약이다.

### 2. 포지셔닝 맵

2x2 포지셔닝 맵을 글로 설명한다(이미지를 그릴 수 없으므로).

- 이 시장에 맞는 두 축을 정의한다(예: "사용 편의성 대 기능의 깊이" 또는 "가격 대 엔터프라이즈 대응 수준")
- 각 경쟁사를 한 사분면에 놓고 한 문장으로 근거를 댄다
- 사용자의 제품을 놓고 전략적 시사점을 강조한다

### 3. 기능 비교표

| 기능 / 역량 | [자사 제품] | [경쟁사 A] | [경쟁사 B] | [경쟁사 C] |
|---|---|---|---|---|
| [기능] | ✅ / ❌ / 🟡 부분 | | | |

✅(있음), ❌(없음), 🟡(부분적/제한적)를 쓴다. 차이가 중요한 판매 포인트나 위험이 되는 기능에는 "전략 메모" 열을 추가한다.

10~15행을 넣는다. 사용자가 기능 정보를 주지 않았다면 어느 칸을 확인해야 하는지 적는다.

### 4. 메시지 분석

경쟁사마다 공개된 메시지(웹사이트 헤드라인, 태그라인, 핵심 가치 제안)를 분석한다.

**[경쟁사 이름]**
- **핵심 주장:** [그들이 한다고 말하는 것]
- **타깃 고객 신호:** [언어와 이미지로 볼 때 누구를 겨냥하는 것으로 보이는지]
- **감정적 훅:** [두려움 / 열망 / 권위 / 속도 / 단순함]
- **메시지의 빈틈이나 약점:** [그들이 다루지 않아 자사 제품이 차지할 수 있는 것]

### 5. SWOT 요약

이 경쟁 구도 안에서 사용자 제품의 깔끔한 SWOT를 만든다.

- **강점:** [진짜 차별점 2~3개]
- **약점:** [솔직한 빈틈이나 취약점 2~3개]
- **기회:** [활용할 시장의 빈틈이나 경쟁사 약점 2~3개]
- **위협:** [지켜봐야 할 경쟁사의 움직임이나 시장 변화 2~3개]

### 6. 전략적 권고

분석에 근거한 실행 가능한 권고 3~5개. 각각 다음 형태로 쓴다. **"[관찰]을 고려할 때, [자사 제품]은 [결과]를 위해 [행동]해야 한다."**

## 채점 기준 (0~40)

이 스킬의 결과물은 넘기기 전에 채점한다. 32점 이상이면 내보낼 수 있는 수준이다.

| 항목 | 0 | 5 | 10 |
|---|---|---|---|
| 맵의 의미 | 축이 일반적이다(가격 × 품질) | 시장에 맞는 축이지만 위치의 근거가 없다 | 축이 이 시장의 실제 구매 갈등을 담고 있고 모든 배치를 방어할 수 있다 |
| 비교의 깊이 | 기능표가 체크 표시뿐이다 | 일부 메모와 함께 기능을 비교했다 | 차별점마다 그 차이가 왜, 누구에게 중요한지 설명하는 전략 메모가 있다 |
| SWOT의 정직성 | 약점과 위협을 듣기 좋게 누그러뜨렸다 | 정직하지만 우선순위가 없다 | 약점과 위협을 꾸밈없이 적고, 얼마나 걱정해야 하는지에 따라 순위를 매겼다 |
| 권고의 구체성 | 일반적인 전략 조언이다 | 실행 가능하지만 발견 내용과 연결되지 않는다 | 각 권고가 "[관찰]을 고려할 때 [결과]를 위해 [행동]" 형태를 따르고 분석으로 거슬러 올라간다 |

## 품질 점검

- [ ] 포지셔닝 맵의 축이 의미 있고 이 시장에 특정되어 있다
- [ ] 기능표에 핵심 차별점에 대한 전략 메모가 있다
- [ ] 메시지 분석이 언급된 모든 경쟁사를 다룬다
- [ ] SWOT가 정직하다. 약점과 위협을 누그러뜨리지 않았다
- [ ] 권고가 일반적인 전략 조언이 아니라 구체적이고 실행 가능하다

## 피해야 할 패턴

- [ ] 품질 차이를 적지 않은 채 기능 보유 여부를 경쟁사 간에 동등하게 표시하지 않는다. 두 제품 모두 "리포트" 기능이 있어도 한쪽이 의미 있게 더 나을 수 있다
- [ ] 근거 없이 사용자의 제품을 가장 유리한 사분면에 놓지 않는다. 실제 경쟁 압력을 무시한 자기중심적 포지셔닝 맵은 전략적 가치가 없다
- [ ] SWOT에서 약점이나 위협을 누그러뜨리지 않는다. 강점만 내세우는 SWOT는 전략 도구가 아니라 홍보 문서다
- [ ] 경쟁사의 역량에 대한 확인할 수 없는 주장을 가정이라고 표시하지 않은 채 넣지 않는다. 소문을 사실처럼 제시하면 분석의 신뢰도가 무너진다

## 요청 예시

- "[제품]과 [경쟁사 A], [경쟁사 B]의 경쟁사 분석을 해 줘"
- "[경쟁사]의 포지셔닝을 해부해 줘"
- "[시장]의 경쟁 구도를 정리해 줘"
- "[경쟁사]와 비교한 우리 제품의 SWOT를 만들어 줘"
