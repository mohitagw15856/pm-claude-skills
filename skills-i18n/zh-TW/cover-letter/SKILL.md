# 求職信

大多數求職信都是讀者會跳過的客套話。好的求職信只做一件事：用像真人說話的語氣，把*你的具體證據*和*這家公司的具體需要*連線起來。這個技能寫一封緊湊、定製的信，沒有"我寫信是為了申請……"，也不復述簡歷，讓人願意讀完。

## 所需輸入

僅在尚未提供時詢問：

- **崗位和公司**，以及職位描述（信必須針對它來寫）。
- **為什麼是這家公司**：真實的理由，例如對方的產品、使命、最近的動作（避免空泛的恭維）。
- **你最有力、最相關的兩到三個證據**：能對應到對方需求的成就。
- **語氣**：溫和專業（預設），或按公司文化更正式或更有創意。

## 輸出格式

一封三到四段的信（英文約 250 到 350 詞，中文約 400 到 600 字）：

> [姓名] · [電子郵件] · [電話] · [日期]
> 尊敬的 [招聘經理姓名，不知道時寫"招聘團隊"]：

**開頭鉤子（一小段）**：開門見山寫出你寫信給*他們*的具體理由，即與對方產品、使命或當下動向的真實聯絡，以及你想要的崗位。不要寫"我寫信是為了申請"。

**證據（一到兩段）**：核心部分：挑出崗位最重要的兩到三項需求，每項用一個具體結果說明你做過。把你的證據對應到他們的問題；不要複述簡歷，而是*解讀*它。

**結尾（一小段）**：你能帶來什麼、真誠的熱情，以及一句面向未來的話（"很希望能和您聊聊……"）。自信，而不是急切。

> 此致，[姓名]

**語氣提示**（給使用者）：保持像人說話：主動語態，不用生僻詞。讀出來；如果聽起來像機器人，就刪。

## 品質檢查

- [ ] 開頭針對這家公司，不能原樣發給另一家僱主
- [ ] 每個證據點都把一個真實、有數字的結果對應到崗位明確的需求之一
- [ ] 它補充簡歷（解讀和連線），而不是重複簡歷的要點
- [ ] 英文約 350 詞以內；段落緊湊、易掃讀
- [ ] 語氣像真人，不像模板
- [ ] 能找到收信人姓名時寫明姓名

## 反模式

- [ ] 不要以"我寫信是為了申請……職位"開頭：它浪費了最有價值的一行
- [ ] 不要複述簡歷：求職信增加的是聯絡和背景，而不是重複的清單
- [ ] 不要空泛恭維（"貴公司聲譽卓著"）：寫出真實、具體的東西
- [ ] 不要湊滿一頁：緊湊的四段勝過一整頁填充
- [ ] 不要顯得急切或傲慢：目標是自信和真誠的興趣

## 依據

現代求職信寫法：具體的開頭鉤子、證據對應需求、真人的語氣。
