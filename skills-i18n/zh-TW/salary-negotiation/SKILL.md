# 薪資談判

大多數人少拿了錢，是因為他們帶著焦慮而不是準備去談。這個技能用計劃代替緊張：按**總薪酬**（而不只是基本工資）比較 offer，以 BATNA 為錨設定目標價和底線，用你的價值來支撐要價，並寫好還價話術，包括基本工資之外那些往往更容易談成的項目。

## 所需輸入

僅在尚未提供時詢問：

- **offer**：基本工資、獎金、股權、簽約獎金和其他組成部分（以及競爭 offer，如有）。
- **你的處境**：當前薪酬、你的 BATNA（最佳替代方案，例如另一個 offer 或留在現職），以及雙方各自有多需要對方。
- **市場資料**：該崗位、職級、地點的可比薪資範圍（levels.fyi、Glassdoor、同行），如有。
- **你在意什麼**：現金還是股權增值、靈活性、職位、入職日期。

## 輸出格式

### 談判計劃：[公司] 的 [崗位]

**1. 總薪酬比較**：絕不只比基本工資。列出各 offer 和你當前（或替代方案）的年度總薪酬（用輔助指令碼）。股權和獎金常常會改變排序。

**2. 你的數字**：**目標價**（有野心但站得住）、**底線**（低於此就拒絕）和**錨點**（開價略高於目標價）。三者都以市場和你的 BATNA 為錨。

**3. 籌碼判斷**：你有多少籌碼（競爭 offer？稀缺技能？對方在流程上已經投入很多？），以及如何使用而不虛張聲勢。

**4. 理由**：基於價值的要價理由：你的證據（影響、可比薪酬、競爭 offer），用合作的方式表達（"我很期待加入；為了讓這件事成……"）。

**5. 還價話術**：以下情況的具體措辭：還價基本工資、回應"這已經是我們的上限"，以及**基本工資之外的籌碼**（簽約獎金、股權、職位或職級、入職日期、遠端、調薪評估時間），在基本工資談不動時這些往往能談。

**6. 底線計劃**：如果對方達不到你的底線，你會怎麼做（以及為什麼提前決定這件事才是你真正的力量）。

## 程式輔助

`scripts/comp_compare.py`（只用標準庫）計算各 offer 的年度總薪酬，讓比較口徑一致（股權按年攤銷，簽約獎金按年折算）：

```bash
# offers.json: [{"name":"Offer A","base":160000,"bonus":24000,"equity_total":200000,"equity_years":4,"signing":20000}, ...]
python3 scripts/comp_compare.py offers.json
python3 scripts/comp_compare.py offers.json --signing-years 1 --json
```

## 品質檢查

- [ ] 按**總薪酬**比較 offer，而不只是基本工資（包括股權、獎金、簽約獎金）
- [ ] 設定了目標價、底線和錨點，並與市場和 BATNA 掛鉤
- [ ] 理由基於價值、有證據，而不是"我需要更多"
- [ ] 包含基本工資之外的籌碼（簽約獎金、股權、職位、入職日期、遠端）
- [ ] 底線在談話*之前*就已決定

## 反模式

- [ ] 不要只比基本工資：總薪酬才是真實的數字，股權和獎金常常改變哪個 offer 更好
- [ ] 不要在沒有提前決定底線的情況下談判：底線是你籌碼的來源
- [ ] 不要虛構一個並不存在的競爭 offer：一旦被追問，你會失去全部信譽
- [ ] 不要開價過低或接受第一個數字：第一個 offer 幾乎總有空間
- [ ] 不要只盯著基本工資：基本工資封頂時，簽約獎金、股權、職級和入職日期常常可以談

## 依據

原則談判法（*Getting to Yes*，Fisher 與 Ury：BATNA、關注利益而非立場）在薪酬談判中的應用。
