# 押金追回

押金爭議在退租那天就決定了勝負，比房東做任何決定都早好幾周：有每面牆帶時間戳照片、完成了交房檢查、書面留下新地址的租客能拿回押金；只有記憶的租客只能去談。這個技能覆蓋兩個階段：還能進房時的證據流程，以及收到扣款後的質疑與升級階梯。它圍繞幾乎決定每個爭議的那條界線：正常損耗（房東的經營成本，在大多數地方不能扣）與損壞（你的責任）。

## 這個技能產出什麼

- **退租流程**：照片和影片巡查、交房檢查請求、清潔收據檔案、新地址告知信
- **扣款質疑**：每項扣款分為損耗、損壞或無依據，並附回應
- **升級階梯**：明細請求、催款信，以及期限計算（標註取決於當地法規）
- **小額訴訟準備清單**：金額值得時，要帶什麼，以及這類庭審實際上怎麼進行

## 所需輸入

如未提供，請詢問：
- **所處階段**：還住在房子裡（執行證據流程，價值最高）、已搬出等待退還，還是已收到扣款明細（質疑階段）
- **已有的書面材料**：租約中關於押金的條款、入住檢查記錄（如果沒有，這本身就有用）、入住和退租時的照片、所有溝通記錄
- **數字**：押金金額、被扣金額、退租後過了多久（退還期限因地而異，往往很短，時間可能已經是租客最有力的論點）
- **房東型別**：個人房東還是物業管理公司；階梯的語氣相同，但公司看流程，個人房東看具體細節

## 框架：損耗與損壞的規則

1. **具體劃線：** 褪色的牆漆、輕微擦痕、地毯上走出來的痕跡、小釘孔屬於損耗（時間造成的，通常不能扣）。汙漬、燙痕、破洞、壞掉的設施、未經同意的刷漆屬於損壞（某件事造成的）。填縫變暗是損耗；瓷磚開裂是損壞。每項扣款都按這條線歸類，邊界情況標註因地而異。
2. **損壞也要計算折舊：** 一塊用了 8 年的地毯因為一處汙漬報廢，房東卻按全新價格收費，等於讓你為升級買單。按使用年限折算是標準的反駁，質疑信會用算術來說明。
3. **證據勝過形容詞：** 退租巡查要系統：每個房間、每面牆、家電內部、各種表，帶時間戳，並在手機以外備份。配對的入住照片（或房東本應提供卻沒有的入住檢查記錄）為之後的每個論點定下框架。
4. **程式是雙刃劍：** 退還或列明細的期限、提供收據的要求、新地址規則，都因地而異，常常有利於租客，有時對惡意扣押還有加倍賠償。信件引用這些規則的*類別*，並標註需在當地核實；已經錯過的期限按經過的天數指出。
5. **按時間表升級，而不是按情緒升級：** (a) 書面要求提供扣款明細和收據；(b) 質疑信：逐項列出、附證據、寫明要求的金額、給出期限、說明下一步；(c) 正式催款函，讀起來就像它將成為的小額訴訟起訴狀；(d) 小額訴訟：專為這類金額設計，通常不需要律師，準備清單基本就是已經建好的證據檔案。

## 輸出格式

# 押金追回：[金額]，階段：[證據流程 / 等待退還 / 質疑扣款]

## [階段一] 退租流程
[按房間的巡查清單 · 交房檢查請求措辭 · 要保留的收據 · 註明日期的新地址告知信]

## 扣款質疑
| 被扣項目 | 金額 | 損耗 / 損壞 / 無依據 | 回應（適用時附折舊計算） |
|---|---|---|---|

## 升級階梯
[每一級附完整信件、期限，以及時間已過時的經過天數 · 加倍賠償類別標註需在當地核實]

## 小額訴訟準備（如果走到這一步）
[成本賬（訴訟費與金額對比）· 證據冊的順序 · 庭審如何進行 · 常見的庭前和解]

> 押金期限、扣款規則和處罰條款因地而異；引用具體數字前請先核實當地規定；正因如此，這裡的信件只引用規則類別。不構成法律意見。

## 品質檢查

- [ ] 每項扣款都分為損耗、損壞或無依據，並附理由，而不是籠統處理
- [ ] 凡是對舊物按全新價收費的地方都附了折舊計算
- [ ] 信件的語氣逐級加強，同時始終適合在法庭上閱讀
- [ ] 因地而異的規則以標註的類別出現，絕不斷言具體數字
- [ ] 小額訴訟部分包含真實的成本賬，而不只是操作步驟

## 反模式

- [ ] 不要為了顯得講理而讓步損耗項目：那條線就是整個爭議
- [ ] 不要帶著怒氣寫：每封信都是證據一號；讓事實來表達分量
- [ ] 不要把具體法條或天數當作事實引用：只寫類別，並標註需在當地核實
- [ ] 不要跳過要求明細這一級：很多扣款在第一次要求出示收據時就站不住了
- [ ] 不要讓怒氣決定是否起訴：準備清單的第一行就是算賬
