# 離職協議解讀

離職補償協議是一筆交易：公司買的是你對權利主張的放棄，價格可以談，但只有一次機會，就是簽字之前。這個技能在你必須做決定的那一週、在衝擊還很強烈的時候，解讀這筆交易到底買賣了什麼。

## 這個技能產出什麼

- **用一段話直說這筆交易**：他們付什麼，你放棄什麼
- **逐條解讀**，帶 🔴🟡🟢 嚴重程度
- **時間表**：考慮期和撤回期（40 歲以上的規則可能不同），日期計算出來
- **值得提的請求**：按成功可能性排序，附措辭

## 所需輸入

僅在未提供時詢問：
- **協議文字**（貼上；部分也可以，說明缺了什麼）
- **基本情況**：工齡、崗位、基本工資、未歸屬的股權，以及協議寫的補償金額
- **大致所在地**：放棄權利條款的效力和支付規則因司法轄區而異；絕不猜測
- **最在意什麼**：現金、醫療保障的過渡期、離職說法與推薦信，還是股權

## 框架：要看什麼

- **放棄範圍**（🔴 區域）：放棄的權利主張，與法律上*不能*放棄的權利（失業金、工傷賠償、向行政機構投訴，取決於轄區，需標註）；警惕放棄*未來*的權利主張。
- **補償算術**：按工齡計算的週數，與該崗位或職級的一般水平對比；未歸屬股權、按比例的獎金和未休假期折現是否出現。對這些事項的沉默是一個可以提的請求，而不是答案。
- **附加條件**（🟡）：不貶損條款（雙向還是單向？）、沒有時間上限的配合條款、重新確認競業限制（有時會*新加*競業條款，🔴）、協議本身的保密。
- **醫療保障**：離職後醫保延續（如美國 COBRA 類）的費用：誰付、付多久；多一個月由公司承擔的醫保，常常是整個談判裡最容易得到的"同意"。
- **時間表**：考慮期（適用年齡歧視規則時通常為 21 或 45 天）和撤回期；提前簽字換不來任何東西；把實際日期算出來。

## 輸出格式

### 離職協議解讀：[公司]
**1. 這筆交易：** 他們付 [X]；你放棄 [範圍]，值不值？[一段話的判斷]
**2. 解讀表** | 條款 | 寫了什麼 | 對你意味著什麼 | 嚴重程度 |
**3. 🚩 排序的風險點**：每項寫出原文、實際代價、要提的修改
**4. 金錢地圖**：寫明的補償，與未提及的事項（股權、獎金、假期、醫保）對比，每項標為有 / 沒有 / 要提
**5. 時間表**：簽字截止日和撤回截止日，計算出來
**6. 請求**：2 到 4 個，按可能性排序，附具體措辭（"如果醫保延續能延長到六個月，我本週就可以籤"）

結尾原文寫明：*"這是通俗解讀，不構成法律意見。放棄權利的相關法律因司法轄區而異；簽字前花一小時請勞動法律師審閱，通常是這份協議裡最值得花的錢。"*

## 品質檢查

- [ ] 第一部分把這筆交易說成一次購買
- [ ] 每個未提及的事項（股權、獎金、假期、醫保）都標為有、沒有或要提
- [ ] 考慮期和撤回期的日期是算出來的，而不是描述的
- [ ] 任何新增的限制性條款都用 🔴 醒目標出
- [ ] 請求按可能性排序，並附具體措辭
- [ ] 請律師審閱一小時的那句話原文出現

## 反模式

- [ ] 不要淡化這一刻：讀者剛剛失去工作；清楚就是善意
- [ ] 不要把 offer 當作最終方案：它是用放棄權利換來的開價
- [ ] 不要把取決於轄區的放棄規則說成普遍適用
- [ ] 不要放過"標準協議"：標準只是公司對自己偏好條款的叫法
- [ ] 不要建議籤或不籤：解讀、定價，然後把決定連同日期交還給使用者
