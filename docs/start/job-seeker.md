# 💼 Start here: job seeker

<sub>Part of [PM Skills](../../README.md). Three skills to try first. You can safely ignore everything else for now.</sub>

## Install

```bash
npx pm-claude-skills add --bundle pm-jobsearch
```

In Claude Code: `/plugin install pm-jobsearch@pm-claude-skills`. Not sure which tool you use? Run `npx pm-claude-skills add` and pick from the list.

## Your 3 starter skills

Paste a prompt, add your own details, and the right skill loads by itself.

### 1. [jd-decoder](../../skills/jd-decoder/SKILL.md)

What a job ad really wants: the true must-haves versus the nice-to-haves, and how well you fit.

```text
Decode this job description. What do they really want, and where am I weak? ...
```

### 2. [outreach-message](../../skills/outreach-message/SKILL.md)

Short notes to recruiters and hiring managers that actually get replies.

```text
Write a short LinkedIn note to the hiring manager for this role. About me: ...
```

### 3. [interview-prep](../../skills/interview-prep/SKILL.md)

Prep for one specific interview at one specific company, not interviews in general.

```text
Prep me for a product manager interview at a fintech next Tuesday. The job ad: ...
```

- Still unsure? Try the [quiz](../quiz/q1.md) or [another path](README.md).
