# 🎓 Start here: student

<sub>Part of [PM Skills](../../README.md). Three skills to try first. You can safely ignore everything else for now.</sub>

## Install

```bash
npx pm-claude-skills add --bundle pm-students
```

In Claude Code: `/plugin install pm-students@pm-claude-skills`. Not sure which tool you use? Run `npx pm-claude-skills add` and pick from the list.

## Your 3 starter skills

Paste a prompt, add your own details, and the right skill loads by itself.

### 1. [exam-prep-planner](../../skills/exam-prep-planner/SKILL.md)

A realistic revision plan built on spaced repetition and retrieval practice, one that survives a real week.

```text
I have three exams in five weeks: statistics, economics and law. Build me a study plan.
```

### 2. [study-notes-synthesizer](../../skills/study-notes-synthesizer/SKILL.md)

Lecture notes, slides and readings turned into one exam-ready study guide.

```text
Turn these lecture notes into one exam-ready study guide: ...
```

### 3. [personal-statement](../../skills/personal-statement/SKILL.md)

A personal statement that shows fit and motivation, and sounds like you.

```text
Help me write my personal statement for a computer science degree. Some things about me: ...
```
