# 🚀 Start here: founder

<sub>Part of [PM Skills](../../README.md). Three skills to try first. You can safely ignore everything else for now.</sub>

## Install

```bash
npx pm-claude-skills add --bundle pm-founders
```

In Claude Code: `/plugin install pm-founders@pm-claude-skills`. Not sure which tool you use? Run `npx pm-claude-skills add` and pick from the list.

## Your 3 starter skills

Paste a prompt, add your own details, and the right skill loads by itself.

### 1. [startup-idea-validator](../../skills/startup-idea-validator/SKILL.md)

Your idea tested the way a sharp investor would: problem, market, wedge, moat, why now, and the cheapest way to test it.

```text
Pressure-test my idea: a booking and payments tool for independent physios.
```

### 2. [runway-planner](../../skills/runway-planner/SKILL.md)

Months of runway left, whether you are default alive, and what to cut or change before you raise.

```text
We have £400k in the bank and burn £38k a month, growing 4% a month. When do we need to raise?
```

### 3. [investor-cold-email](../../skills/investor-cold-email/SKILL.md)

A short, specific investor email with traction up front and a clear ask.

```text
Write a cold email to a seed investor who backs vertical SaaS. Our traction: ...
```
