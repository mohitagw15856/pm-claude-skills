# 🧭 Start here: product manager

<sub>Part of [PM Skills](../../README.md). Three skills to try first. You can safely ignore everything else for now.</sub>

## Install

```bash
npx pm-claude-skills add --bundle pm-essentials
```

In Claude Code: `/plugin install pm-essentials@pm-claude-skills`. Not sure which tool you use? Run `npx pm-claude-skills add` and pick from the list.

## Your 3 starter skills

Paste a prompt, add your own details, and the right skill loads by itself.

### 1. [prd-template](../../skills/prd-template/SKILL.md)

A complete PRD: problem, user stories, scope, success metrics and open questions.

```text
Write a PRD for a referral programme for our B2B app. Here are my notes: ...
```

### 2. [stakeholder-update](../../skills/stakeholder-update/SKILL.md)

A short update for leadership with the bottom line first, then progress, risks and the help you need.

```text
Turn this week into a BLUF update for my VP. What happened: ...
```

### 3. [meeting-notes](../../skills/meeting-notes/SKILL.md)

Decisions, owned actions with deadlines, and open questions from any meeting.

```text
Turn these raw meeting notes into decisions and actions with owners: ...
```

## When you are ready

- The full bundle: **[pm-essentials](../../plugins/pm-essentials/)**, the documents a product person writes every week.
- Then: [pm-discovery](../../plugins/pm-discovery/) for interviews and assumptions, [pm-strategy](../../plugins/pm-strategy/) for narratives and stakeholders, [pm-data](../../plugins/pm-data/) for metrics and experiments.
- Still unsure? Try the [quiz](../quiz/q1.md) or [another path](README.md).
