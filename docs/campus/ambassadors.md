# 校园大使计划

[校园资料包](README.md) · [申请（GitHub）](https://github.com/mohitagw15856/pm-claude-skills/issues/new?template=campus-ambassador.yml) · [申请（Gitee）](https://gitee.com/mohitagw/pm-claude-skills/issues)

校园大使在自己的学校介绍 PM Skills，带同学完成第一次开源贡献，再把同学的真实需求带回来。这是一个志愿项目，没有报酬，也没有任何考核指标。

## 大使做什么

- **办活动**：每学期至少一场分享会或工作坊。幻灯片、工作坊流程和海报说明都是现成的，见[校园资料包](README.md)。
- **带贡献**：帮同学从[翻译认领板](../zh/translation-board.md)上认领翻译，或者把工作坊上写的技能提交上来。
- **带反馈**：同学们最常问什么、哪些技能不符合国内情况、还缺什么技能，用 Issue 告诉我们。
- **守规矩**：活动中强调学术诚信，不收集同学的个人信息，不以项目名义收费或承诺任何东西。

## 大使能得到什么

- 在仓库的校园大使名单里列出你的名字、学校和 GitHub 或 Gitee 账号（你同意的话）
- 你和同学的贡献都会出现在贡献者墙和译者榜上，是可以在简历里写、面试时打开给人看的开源经历
- 提前看到新技能，参与技能需求的讨论
- 维护者可以为你组织的活动写一段客观的说明（例如活动时间、规模和你的职责），只写事实

## 谁可以申请

- 在读的本科生、研究生或高职学生，任何专业
- 用过至少一个技能，愿意组织一场活动
- 社团负责人、助教优先，但不是必须

## 怎么申请

1. 在 GitHub 上用[校园大使申请模板](https://github.com/mohitagw15856/pm-claude-skills/issues/new?template=campus-ambassador.yml)开一个 Issue；访问 GitHub 不方便的话，在 [Gitee Issue](https://gitee.com/mohitagw/pm-claude-skills/issues) 选"校园大使申请"模板。
2. 写清楚学校、你想办的第一场活动和大概时间。**不要在 Issue 里留手机号、学号或微信号**，Issue 是公开的。
3. 维护者会在 Issue 下回复。活动办完后，在同一个 Issue 下留言写一句总结，就完成了第一学期。

## 常见问题

**一个学校可以有几位大使？** 可以有多位，建议在 Issue 里互相认识，一起办活动。

**不会讲课怎么办？** 幻灯片每页都有讲者备注和时间点，彩排一次就够。也可以先只办工作坊，让同学自己动手。

**可以修改资料吗？** 可以，资料是 MIT 协议。改得好的地方欢迎提 PR，下一位大使就能用上。

**学校要求活动有指导老师？** 把[校园资料包](README.md)发给老师看，内容里已经包含学术诚信部分。
