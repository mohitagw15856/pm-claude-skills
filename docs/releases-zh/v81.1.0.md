# v81.1.0：开源项目上线工具包、3D 讲解页和技能科技树

**1235 个技能，142 个技能包。**

## 新增

- **pm-oss-launch**（9 个技能）：把个人项目做成陌生人愿意安装、信任和参与的开源仓库：按用户收益重写 README、不用注册的演示数据、从竞品导入数据、新手友好的 Issue、许可证审计和 NOTICE 文件、两周一次的小版本、一条命令自部署、只读 MCP 服务，以及 20 秒演示视频脚本。
- **pm-3d-explorer**（4 个技能）：给一个主题，生成可以拆开看、点击看标注、还能做小测验的 3D 讲解页；每个标注都要注明可信来源。
- **pm-china-exams**（5 个技能）：申论、公务员结构化面试、考研规划、校招与三方协议、国企面试。
- **pm-china-work** 新增：飞书文档、钉钉日志、企业微信公告、需求评审、职级对标。
- **技能科技树**：把整个技能库画成一棵科技树，可以搜索、复制安装命令、为想要的技能投票。
- **魔搭社区**：在线试用创空间、技能路由模型、6 个技能上架 Skills 中心、MCP 服务上架。

## 国内安装

```bash
npx --registry=https://registry.npmmirror.com pm-claude-skills add --agent trae --bundle pm-china-work,pm-china-exams
```
