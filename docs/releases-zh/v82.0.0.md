# v82.0.0：老师、家长、外贸、制造业都能用，新增韩国与东南亚，轻量技能和团队同步

**1285 个技能，152 个技能包。**

## 新增技能包

- **pm-china-teachers 教师**：新课标教案、主题班会、家长会、期末评语、公开课与说课稿。
- **pm-china-parents 家长**：幼升小与小升初、家校沟通、课外安排、辅导作业。
- **pm-china-trade 外贸**：询盘回复、信用证审单、报价单、报关单证。
- **pm-china-manufacturing 制造业**：8D 报告、5S 检查、质量追溯、作业指导书。
- **pm-china-yearend 述职季**：述职 PPT、年终奖与个税、明年 OKR 与个人发展计划。
- **适老化**：帮爸妈办事（医保、社保、养老金、银行、防诈骗），医保和社保技能可以输出“长辈版”。
- 互联网黑话翻译器、粤语文案，以及韩国、日本、新加坡和马来西亚技能包；28 个技能新增越南语和印尼语译文。

## 更好上手

- README 重新设计：一句话上手、选择你的路径、四道题的小测验、“今天想做什么”流程图，以及每天更新的今日技能、考试倒计时和二十四节气横幅。
- 拼音搜索（输入 `zb` 就能找到周报），技能搜索支持中文。
- 在线试用支持魔搭的免费额度。

## 更多用法

- **内网离线包**：附在本版本的 Gitee 发行版里，含统信 UOS、银河麒麟安装说明。
- **WPS 与 Word 加载项**：在文档里插入技能模板，或用自己的模型接口处理选中的文字。
- **飞书多维表格模板**：周报、OKR、求职进度。
- **群聊机器人**：飞书、钉钉、企业微信和 Discord。
- **小工具**：拜年语、调休、述职大纲。
- **轻量技能**：`add --lite` 给本地小模型（Qwen 7B、DeepSeek 蒸馏模型）用。
- **团队技能清单**：`.pm-skills.json` 加上 `sync`，让团队每台电脑装的技能保持一致。
- **个人档案**：`profile` 记录你的城市和职位，技能会按你的城市套用社保、公积金等地方规定。

## 国内安装

```bash
npx --registry=https://registry.npmmirror.com pm-claude-skills add --agent trae --bundle pm-china-teachers,pm-china-parents
```
