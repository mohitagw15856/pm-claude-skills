# China launch kit

Drafts for introducing PM Skills to Chinese developers and professionals. They are written to be posted by the maintainer from their own accounts. Nothing here is posted automatically.

| File | Platform | Audience | Format |
|---|---|---|---|
| [juejin.md](juejin.md) | 掘金 Juejin | Developers using AI coding tools | Technical article, about 1,800 characters |
| [zhihu.md](zhihu.md) | 知乎 Zhihu | Professionals asking how to use AI at work | An answer to a common question, plus a short article version |
| [v2ex.md](v2ex.md) | V2EX | Developers, sceptical of promotion | A short "分享创造" post |
| [bilibili.md](bilibili.md) | 哔哩哔哩 Bilibili | People who learn by watching | A 3-minute demo script with shot list |
| [issues.md](issues.md) | GitHub | Chinese users of the repository | A usage survey and a call for a Chinese reviewer |

## Before posting

1. **Check the Chinese once more.** These were written carefully, but a native reader should read each before it goes out under your name.
2. **Post where the audience already is.** Juejin and V2EX for developers; Zhihu for the workplace and life-admin skills.
3. **Lead with one useful skill, not the count.** "帮你写周报的开源技能" lands better than "1000 多个技能".
4. **Be honest about reachability.** GitHub Pages and the hosted endpoint can be slow or blocked in mainland China. Point people to the npm mirror install and the local MCP server, which need no overseas network.
5. **Answer comments in Chinese** for the first week. That is when most of the useful feedback arrives.

## Platform rules to respect

- V2EX moves self-promotion out of most nodes. Post only in 分享创造, say plainly that you made it, and do not repost.
- Zhihu answers that are thin advertisements get folded. Answer the question fully first; mention the project once.
- Juejin welcomes technical depth. The article explains how skills and routing work, not only what the project is.
