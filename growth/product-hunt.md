## Description
Generic AI gives you filler. PM Skills is an open-source library of 1,117 plain-markdown "skills" that teach your AI to do one real task to a senior professional's standard — decode a lease, write a PRD, negotiate a raise, plan after a death, respond to debt collectors. Run any of them free in the browser (no key needed), or install into Claude Code, Cursor, ChatGPT, Gemini and 10+ tools. MIT-licensed, no telemetry, every skill passes a spec + security gate in CI.
