# Skill of the Week — the steady distribution engine

One post a week, each showing **one skill solving one real problem**, with the actual output. This is the compounding, low-effort channel: longtail SEO, a reason to post consistently, and a library of shareable proof. Cross-post to Medium (use the `medium-pm-articles` skill), dev.to, LinkedIn, and the newsletter.

## The format (same every week — repeatable = sustainable)
1. **The problem**, in a real person's words. *"My landlord is keeping my deposit and I don't know if that's legal."*
2. **The skill** that answers it, one line on what it does.
3. **The actual output** — run it in the Playground, paste the real result. This is the whole point; show, don't tell.
4. **One CTA:** try it free in the Playground (link), and ⭐ the repo if it helped.

## Rotation strategy
Alternate **emotional/human** weeks (grief, reentry, caregiving, hardship — these get *shared*) with **builder/dev** weeks (prompt-debugging, ai-agent-reliability, claude-project-setup — these get *starred*). Human posts bring reach; dev posts bring stars. You need both.
