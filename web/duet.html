⚡ Skills for proactive agents

Claude Duet, OpenAI Dots and similar agents read your connected apps and work while you are away. A skill that is fine in a chat you are watching can go wrong in a brief you are not. It can pad, skip its sources, act instead of drafting, or say "done" about a draft. These skills are written so that doesn't happen.

Honest status: every skill here is designed for Duet: it follows the library's Duet conventions, and nobody has run it on Duet yet. Duet is a waitlisted research preview. If you have access, file a Tested on Duet report and the skill moves up a tier, with your report linked.

Set up in this order

  1. prepare-for-duet: audit your memory, connectors and inbox habits before the agent starts
  2. standing-orders: the one-page manual: always, never, VIPs, tone, when to stop and ask
  3. approval-policy-designer: per app, what it may do alone, what it must ask about, what it must never do
  4. morning-brief-designer and interrupt-rules: what the brief says, and what may interrupt you between briefs
  5. agent-kill-switch-plan: how to stop it in under a minute, written before you need it
Adding a skill to Duet: Duet uses the skills in your Claude account. Download a skill with ⬇ Add to Claude, then in claude.ai open Settings, then Skills, and choose Upload skill. Upload the ZIP as it is; don't unzip it. In Claude Code or other tools, use the install line under each pack.
