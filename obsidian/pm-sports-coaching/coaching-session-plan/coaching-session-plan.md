# Coaching Session Plan

A session that tries to fix five things fixes none. This skill plans a session around one objective, keeps players active for most of the time, and gives the coach a few clear points to say. It works for any team sport and adapts to age, numbers and space.

## What This Skill Produces

- One objective, stated as what players will do better by the end
- A timed plan: arrival activity, warm-up, practices, game, cool-down and debrief
- For each activity: set-up, rules, two or three coaching points, an easier and a harder version
- Equipment list and space layout in words
- Safety and inclusion notes
- Three review questions for after the session

## Required Inputs

Ask for these if not provided:

- Sport, age group and level
- Number of players expected, and how the plan should flex if fewer or more turn up
- Session length, space and equipment
- The objective, or the problem seen in the last match
- Helpers available
- Any players with injuries, additional needs or very different ability

## Framework

1. **One objective.** "Receive on the half-turn under pressure" beats "work on midfield".
2. **Whole, part, whole.** Start with a small game that shows the problem, isolate the skill, then return to a game that rewards it.
3. **High activity time.** Small groups, several balls, no queues. If players are standing for more than a minute, split the group.
4. **Few coaching points.** Two or three per activity, in words a player of that age uses.
5. **Progress and regress.** Change space, numbers, time, or rules to make the same practice easier or harder.
6. **Finish with a game** that scores the objective, for example an extra point for doing the skill.
7. **Debrief in two minutes.** Ask players what worked. Give one thing to practise at home.
8. **Safety.** Check the surface, equipment, weather, hydration and a head-count at start and end.

## Output Format

### Session plan: [team], [date], [duration]

**Objective:** by the end, players will [observable behaviour].
**Numbers:** planned for [n]; if fewer than [n], [change]; if more than [n], [change].
**Equipment:** [list]

| Time | Activity | Set-up and rules | Coaching points | Easier | Harder |
|---|---|---|---|---|---|
| 0 to 5 | Arrival game | | | | |
| 5 to 15 | Warm-up | | | | |
| 15 to 30 | Practice 1 | | | | |
| 30 to 45 | Practice 2 | | | | |
| 45 to 57 | Game | | | | |
| 57 to 60 | Cool-down and debrief | | | | |

**Safety and inclusion:** [checks, adaptations]

**After the session, ask yourself**
1. Did most players achieve the objective, and how do I know?
2. Which activity had the most standing around?
3. What do we carry into the next session?

**Assumptions and gaps**
- [What was assumed about numbers, space or ability]
- [What the coach should adjust on the night]

## Quality Checks

- [ ] There is exactly one objective and the final game rewards it
- [ ] Timings add up to the session length
- [ ] No activity leaves players queueing
- [ ] Each activity has an easier and a harder version
- [ ] Coaching points suit the age group
- [ ] A plan exists for uneven numbers

## Anti-Patterns

- **Do not fill the hour with unrelated drills.**
- **Do not use laps or press-ups as punishment.**
- **Do not lecture.** Keep stoppages under a minute.
- **Do not plan for perfect attendance.**
- **Do not include contact or heading practice** beyond what the governing body allows for the age group; tell the coach to check the current guidance.

## Example Trigger Phrases

- "Plan a 60-minute session on passing for under-9s, twelve players, half a pitch."
- "We keep losing the ball in midfield. Give me tomorrow's session."
- "I only have six cones and four balls. What can I run?"
- "Make this drill harder for the stronger group."
