# Firm Sessions

Sessions of the [Firm](../web/firm.html) land here: dated decision memos with minutes, preserved dissent and a prediction. They are generated by `scripts/firm-session.mjs` through the **Firm session** Action.

The **live** sessions run on this repository's own numbers (`scripts/firm-session.mjs --live`): stars, npm downloads, quality numbers, recent pull requests and open issues. Each session ends in one machine-checkable prediction, which is logged in [`data/firm-ledger.json`](../data/firm-ledger.json) and scored automatically when it falls due (`scripts/score-firm-predictions.mjs`). The track record is at [firm-live.html](https://mohitagw15856.github.io/pm-claude-skills/firm-live.html). Sessions meet weekly once the repository variable `FIRM_LIVE` is `true`, and on manual dispatch otherwise.

Review a memo before acting on it.
