Run the **出海上新 (cross-border launch)** workflow recipe for: $ARGUMENTS

This is a *chain* of skills. Run each stage in order and **carry every stage's output forward as context** for the next. Open with a one-line plan of the 5 stages, then ask once for any essential missing inputs. Don't re-ask between stages.

Run each stage under a clear `## Stage N: <name>` heading:

1. **选市场**: apply the `chuhai-market-entry` skill to choose the first market and positioning, with the regulatory and logistics risks.
2. **选平台**: apply the `crossborder-platform-playbook` skill to choose the platform (Temu, TikTok Shop, Amazon and so on) and the entry route, with fees and rules.
3. **Listing**: apply the `cross-border-listing` skill to write the localised listing: title, bullets, description and keywords for that platform.
4. **种草**: apply the `xiaohongshu-note` skill to write a 小红书 note grounded in a real usage story, checked for restricted advertising terms.
5. **直播**: apply the `livestream-sales-script` skill to write the livestream script: the pitch, objection handling and a compliance check.

Do not invent sales figures, certifications or reviews. Flag anything that needs a lawyer or the platform's own current rules. After the last stage, end with a 5-bullet **"What you now have"** recap linking each artifact to the stage that produced it, and a one-line next step.
