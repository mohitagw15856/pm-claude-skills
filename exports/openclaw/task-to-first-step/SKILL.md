# Task to First Step

The hardest part of a dreaded task is the *starting* — the activation energy. Willpower is the wrong tool; shrinking the step is the right one. This takes the task you've been avoiding and reduces the first move to something almost too small to resist (open the file, write one bad sentence, put on the shoes). Momentum does the rest — but only after the first tiny action gets you moving.

## What This Skill Produces

- **The laughably small first step** — a single physical action so tiny that not doing it feels absurd
- **Why it works** — how that step sidesteps the resistance (it's concrete, immediate, and requires no decisions)
- **The next 2–3 micro-steps** — the follow-ons, each still small, to ride the momentum
- **The "just this" framing** — permission to stop after the first step if needed (which usually means you won't)

## Required Inputs

Ask for these if not provided:
- **The task** — the thing you're avoiding
- **Where you're stuck** — is it starting, or somewhere in the middle
- **Why it feels heavy** — too big, boring, scary, or unclear
- **Your setup** — what's around you (so the first step fits reality)

## Framework: Shrink Until It's Trivial

1. **Find the true first physical action.** Not "write the report" — "open a blank doc and type the title." The first *physical* move, not the task.
2. **Shrink until resistance dies.** If it still feels heavy, make it smaller — "write one bad sentence," "read the first email." The bar should feel almost silly.
3. **Make it decision-free.** The step should require zero further choices — decisions are their own activation cost.
4. **Give permission to stop.** Frame it as "just do this one thing, then you can quit" — which removes the pressure and usually starts a chain.
5. **Queue the momentum steps.** A couple more micro-steps ready, so once moving, there's no fresh cliff.

## Output Format

### Task: [the thing you're avoiding]

**👉 The only first step:** [a tiny, concrete, physical action] — ~[a minute or two].
**Why this works:** [concrete · immediate · no decisions].
**You can stop after that.** (You probably won't.)

**If you're rolling, next:**
2. [micro-step] · 3. [micro-step] · 4. [micro-step]

## Quality Checks
- [ ] The first step is a single physical action, not the task
- [ ] It's shrunk until resistance would feel absurd
- [ ] It requires no further decisions
- [ ] Permission to stop after step one is given
- [ ] A few momentum micro-steps follow

## Anti-Patterns
- **"Just start the report"** — that's the task, not a step.
- **A first step that hides more decisions.**
- **Still-too-big steps** that don't dissolve the resistance.
- **A guilt-laden "you must finish"** framing that raises the barrier.

## Example Trigger Phrases
- "I can't get started on my tax return — help me begin."
- "This project feels too big to start."
- "Break down cleaning the garage so I can actually start."
- "I keep avoiding this email. Help me just start it."
- "Give me a first step so small I can't say no."
