# Think From Another Angle

When you're stuck, thinking harder from the same angle rarely helps — the angle itself is the trap. This re-casts your problem through deliberately different frames: how a curious ten-year-old would see it, how another industry solves the equivalent, what happens at the extremes, what if you did the opposite. Each reframe changes what the problem *is*, and one of them usually pops it open.

## What This Skill Produces

- **The problem, reframed several ways** — recast through distinct lenses (naïve, outsider, another domain, inverted, extreme, "what if this weren't a problem")
- **What each reframe reveals** — the new angle or possibility each one exposes
- **The most useful frame** — the reframe that best unsticks this specific problem
- **A next move** — the concrete action the best reframe points to

## Required Inputs

Ask for these if not provided:
- **The problem** — what you're stuck on
- **How you're currently framing it** — so we can break that frame
- **What you've tried** — so we don't reframe into a dead end
- **What "unstuck" looks like** — the outcome you want

## Framework: Change The Frame, Not The Effort

1. **Name the current frame.** How is the person seeing the problem? That framing is likely the constraint.
2. **Apply distinct lenses.** Recast through genuinely different frames — the ten-year-old, the outsider, another industry's version, the inverse, the extreme, "what if this were the goal not the problem."
3. **Let each redefine the problem.** A good reframe changes what the problem even *is* — not just restates it.
4. **Extract the insight from each.** Say what each frame reveals that the original hid.
5. **Pick the key and act.** Identify the reframe that most unsticks this, and the concrete next move it implies.

## Output Format

### Stuck on: [the problem] · currently framed as [x]

**Reframes**
- 🧒 **Naïve:** [how a beginner sees it] → reveals [x].
- 🌍 **Outsider / another field:** [how they'd solve the equivalent] → reveals [x].
- 🔄 **Inverted:** [the opposite framing] → reveals [x].
- 📏 **Extreme:** [at the limit] → reveals [x].

**Most useful angle:** [the reframe that unsticks it].
**Next move:** [the concrete action it points to].

## Quality Checks
- [ ] Names and breaks the current frame
- [ ] Applies genuinely distinct lenses (not restatements)
- [ ] Each reframe changes what the problem is and reveals something
- [ ] Identifies the single most useful reframe
- [ ] Points to a concrete next move

## Anti-Patterns
- **Restating the problem** in new words (not reframing).
- **Reframes that all say the same thing.**
- **Clever angles with no insight** attached.
- **No pick and no next move** — leaving the person still stuck.

## Example Trigger Phrases
- "I'm stuck on this problem — help me see it differently."
- "Reframe how I'm thinking about my career rut."
- "How else could I look at this conflict?"
- "I keep hitting a wall on this — different angle?"
- "Recast this problem for me."
