# Renovation Scope & Budget

Renovations blow up on budget and timeline because people start without a clear scope — then every decision becomes a costly mid-project scramble. This turns a vague "I want to redo the kitchen" into a defined scope, a realistic budget with a contingency, and a sequence, so you can get quotes from a position of knowledge and spot when a bid is padding or the plan is drifting.

## What This Skill Produces

- **A scoped breakdown** — the work split into components (demo, structural, systems, surfaces, fixtures, finishes)
- **A realistic budget range** — a band per component plus a contingency (renovations reliably surprise), with the big cost drivers named
- **Sequence & timeline** — the order work must happen and a rough duration, including lead-time items
- **Decide-early choices** — the selections that must be locked before work starts to avoid costly changes
- **Where it balloons** — the classic overrun sources (moving plumbing/walls, hidden damage, spec creep, permits)
- **Pre-quote prep** — what to define so quotes are comparable and you're not scoped

## Required Inputs

Ask for these if not provided:
- **The project** — what you want to renovate and the rough vision
- **The space** — size, age of home, current condition
- **Budget reality** — what you hope to spend and how firm
- **Scope ambition** — cosmetic refresh vs. gut/structural changes
- **Location & constraints** — region (prices/permits), DIY appetite, timeline, living-through-it or not

## Framework: Scope It, Band It, Sequence It

1. **Define the scope precisely.** Break the vision into concrete components — vague scope is what quotes exploit and budgets miss.
2. **Budget in bands with contingency.** Give realistic ranges per component and add a meaningful contingency (surprises are the norm, not the exception); name the biggest cost drivers.
3. **Sequence the work.** Order matters (structure → systems → surfaces → finishes) and long-lead items must be ordered early — lay it out.
4. **Front-load the decisions.** Identify the selections to lock before work begins; mid-project changes are where budgets and timelines die.
5. **Name the balloon risks.** Moving plumbing/walls, opening up old homes (hidden damage), spec creep, and permits are the usual overruns — flag them.
6. **Prep for quotes.** Tell them what to specify so bids are comparable, and treat all figures as "verify with local quotes."

## Output Format

### Renovation: [project] · [space] · target budget [x] · [region]

**Scope**
| Component | Included | Budget band |
|---|---|---|
| [demo/structural/systems/surfaces/fixtures/finishes] | | |
**+ Contingency:** [~10–20%].

**Sequence & timeline:** [order of work] · ~[duration] · long-lead items: [order early].
**Decide before starting:** [key selections to lock].
**Where it balloons:** [moving plumbing/walls · hidden damage · spec creep · permits].
**Before you get quotes:** [what to define so bids are comparable].

> Prices, permits, and norms are local — verify the budget with real quotes before committing.

## Quality Checks
- [ ] Scope is broken into concrete components
- [ ] Budget is a range per component with a contingency and named cost drivers
- [ ] Includes work sequence, timeline, and long-lead items
- [ ] Flags the decisions to lock before starting
- [ ] Names the common balloon/overrun sources
- [ ] Defers final numbers to local quotes

## Anti-Patterns
- **A single fixed number** with no range or contingency.
- **Vague scope** that quotes will exploit.
- **Ignoring sequence/long-lead** items.
- **No decide-early guidance** — costly mid-project changes.
- **Presenting estimates as precise** across regions.

## Example Trigger Phrases

- "How much should a bathroom remodel cost, roughly?"
- "Plan my basement finishing project before I get quotes."
- "What order does renovation work happen in?"
- "Where do renovation budgets usually blow up?"
