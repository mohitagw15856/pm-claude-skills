# Habilidad: Mapa de Recorrido del Cliente

Esta habilidad produce un mapa de recorrido del cliente completo que cubre cada etapa, desde la conciencia hasta la defensa. Cada etapa incluye puntos de contacto, acciones del cliente, emociones, puntos de fricción y oportunidades de mejora específicas. El resultado está listo para usar en descubrimiento de productos, diseño UX o talleres de alineación entre funciones.

## Entradas Requeridas

Trabaja a partir de lo que se proporciona. Si falta algo, igualmente produce el resultado completo: rellena cada brecha con una suposición razonable marcada *(asumido, confirmar)* y enumera esas suposiciones al final. Haz una pregunta solo cuando falte el tema central en sí (no hay nada sobre qué escribir).
- **Producto o servicio** siendo mapeado
- **Persona del cliente** — ¿para qué segmento de cliente es este mapa? (sé específico — una persona por mapa)
- **Alcance del recorrido** — de extremo a extremo completo (conciencia → defensa), ¿o una fase específica? (p. ej. solo incorporación)
- **¿Estado actual o estado futuro?** — ¿Mapear cómo funciona hoy, o diseñar cómo debería funcionar?
- **Fuentes de datos** — ¿hay investigación, entrevistas con usuarios, tickets de soporte, comentarios NPS, análisis disponibles?
- **Objetivo del mapa** — ¿qué decisión informará esto? (rediseño, priorización, alineación de stakeholders, nueva característica)

## Etapa 1: Conciencia

*¿Cómo descubre el cliente por primera vez que el producto existe?*

**Objetivo del cliente en esta etapa:** [p. ej. Darse cuenta de que tiene un problema que vale la pena resolver — o encontrar una solución a un dolor específico]

| Elemento | Detalle |
|---|---|
| **Disparador** | [¿Qué evento los hace empezar a buscar? — p. ej. El proceso manual falla / recomendación de un colega / vio un anuncio] |
| **Dónde están** | [Búsqueda en Google / LinkedIn / conferencia / conversación de colegas / boletín de correo] |
| **Qué hacen** | [p. ej. Busca "automatizar incorporación de empleados" / pregunta a colegas en comunidad de RRHH / hace clic en anuncio de LinkedIn] |
| **Emoción** | [😤 Frustrado — abrumado por procesos manuales y esperanzado de encontrar una forma mejor] |
| **Puntos de fricción** | [Número abrumador de opciones / difícil saber qué herramientas son creíbles / no se puede distinguir B2B de B2C en la página de inicio] |
| **Oportunidades** | [Contenido SEO dirigido a la palabra clave del disparador / liderazgo de pensamiento en LinkedIn / presencia en comunidad de pares] |

## Etapa 2: Consideración

*El cliente está evaluando activamente opciones. ¿Qué hacen para decidir?*

| Elemento | Detalle |
|---|---|
| **Objetivo del cliente** | [Reducir de muchas opciones a una lista corta de 2–3] |
| **Qué hacen** | [Lee reseñas en G2/Capterra / mira video de demostración / descarga guía de comparación / pregunta a colegas que usan algo similar] |
| **Puntos de contacto** | [Sitio web / sitios de reseñas / prueba social / flujo de solicitud de demostración / correo de ventas] |
| **Emoción** | [😕 Ansioso — preocupado por hacer la elección equivocada; compras de herramientas pasadas no han dado resultados] |
| **Puntos de fricción** | [Precio no visible en el sitio web / la demostración requiere una llamada antes de ver el producto / no está claro si funciona con su stack actual] |
| **Oportunidades** | [Demostración de autoservicio o tour interactivo del producto / página de precios transparente / calculadora de ROI / estudios de caso de empresas de tamaño similar] |

---

## Etapa 3: Decisión

*El cliente está listo para comprar — o no. ¿Qué los hace comprometerse?*

| Elemento | Detalle |
|---|---|
| **Objetivo del cliente** | [Obtener aprobación de la CHRO y justificar la decisión con un caso de negocio] |
| **Qué hacen** | [Programa llamada de ventas / solicita cuestionario de seguridad / construye caso de negocio interno / negocia contrato] |
| **Puntos de contacto** | [AE / llamada de ventas / revisión de seguridad / contrato / proceso de adquisición] |
| **Emoción** | [😬 Cauteloso — no quiere equivocarse; presentar al liderazgo añade presión] |
| **Puntos de fricción** | [El proceso de ventas es lento / el cuestionario de seguridad toma semanas / los términos del contrato no son estándar y requieren asesor legal] |
| **Oportunidades** | [Preguntas frecuentes de seguridad de autoservicio / contrato estándar con términos predecibles / kit de defensor (diapositivas, plantilla de caso de negocio) para ayudarles a vender internamente] |

---

## Etapa 4: Incorporación

*El cliente ha comprado. Ahora necesita obtener valor rápidamente.*

| Elemento | Detalle |
|---|---|
| **Objetivo del cliente** | [Que el producto funcione y demostrar a su CHRO que fue una buena decisión] |
| **Qué hacen** | [Recibe correo de bienvenida / asiste a llamada de inicio / configura integraciones / invita al equipo] |
| **Puntos de contacto** | [Secuencia de correo de incorporación / lista de verificación de incorporación en el producto / CSM / centro de ayuda / mercado de integraciones] |
| **Emoción** | [😬 Ansioso pero esperanzado — emocionado con el potencial pero estresado por el trabajo de configuración] |
| **Puntos de fricción** | [La configuración es más compleja de lo esperado / IT requerido para SSO pero IT es lento para responder / la incorporación genérica no coincide con su caso de uso] |
| **Oportunidades** | [Rutas de incorporación específicas por rol / conector de IT con plantilla de solicitud rellenada previamente / correo de victoria rápida al día 3 (muéstrales una cosa que ya funciona)] |

**Momento crítico:** [¿Qué momento único en esta etapa determina si se convertirán en un usuario activo o desaparecerán? — p. ej. "La primera vez que el producto les ahorra 30 minutos en una tarea que solían hacer manualmente"]

---

## Etapa 5: Adopción

*El cliente está usando el producto. ¿Están obteniendo valor consistente?*

| Elemento | Detalle |
|---|---|
| **Objetivo del cliente** | [Hacer que el producto sea una parte regular de su flujo de trabajo; demostrar ROI al liderazgo] |
| **Qué hacen** | [Usa características principales diariamente / descubre nuevas características / encuentra una limitación / contacta soporte / asiste a webinar] |
| **Puntos de contacto** | [IU del producto / notificaciones dentro de la app / correo / soporte / comunidad / gerente de éxito del cliente] |
| **Emoción** | [Variable — algunos días 😊 cuando el producto funciona bien; algunos días 😤 cuando encuentra una brecha o bug] |
| **Puntos de fricción** | [La característica que esperaba no está / los reportes no muestran la métrica que el liderazgo quiere / las características avanzadas son demasiado complejas / siente que está infrautilizando lo que está pagando] |
| **Oportunidades** | [Verificación proactiva de CSM al día 30 / descubrimiento de características dentro del producto / tablero de uso para que el cliente vea su propio ROI / comunidad para aprendizaje entre pares] |

**Indicadores de salud de adopción:**
- [Ratio DAU/MAU — ¿cómo se ve saludable?]
- [Característica X usada por el Y% de puestos dentro de Z semanas]
- [Primera encuesta NPS a los 60 días — puntuación objetivo]

## Etapa 6: Defensa

*El cliente ama el producto. ¿Cómo lo conviertes en un motor de referidos?*

| Elemento | Detalle |
|---|---|
| **Objetivo del cliente** | [Resolver problemas más rápido; sentirse como un experto; sentirse valorado como cliente] |
| **Qué hacen** | [Refiere a un colega / escribe una reseña en G2 / participa en estudio de caso / habla en evento / se convierte en usuario avanzado / se une a la comunidad] |
| **Puntos de contacto** | [CSM / comunidad / correo de solicitud de reseña / programa de referidos / alcance de estudio de caso / patrocinio de conferencia] |
| **Emoción** | [😊 Orgulloso — la herramienta es parte de su identidad profesional; se sienten inteligentes por haberla elegido] |
| **Puntos de fricción** | [El programa de referidos es engorroso / no hay forma estructurada de conectarse con pares / el proceso de estudio de caso es lento y requiere esfuerzo de su parte] |
| **Oportunidades** | [Solicitud de reseña en G2 con un clic en el momento de alta satisfacción / comunidad de pares / programa de referidos con recompensa significativa / proceso de estudio de caso que hace la mayor parte del trabajo por ellos] |

## Rúbrica de Puntuación (0–40)

Puntúa cualquier resultado de esta habilidad antes de entregarlo; 32+ es de calidad para lanzar.

| Dimensión | 0 | 5 | 10 |
|---|---|---|---|
| Especificidad de la persona | "Todos los clientes" o un esbozo demográfico que podría ser cualquiera; puntos de contacto genéricos para cualquier producto | Una persona nombrada pero superficial — objetivos y frustraciones podrían aplicarse a cualquier comprador en la categoría | Una persona vívida con rol, objetivo, frustraciones y poder de decisión; cada punto de contacto y fricción es reconociblemente este producto y esta persona |
| Anclaje en evidencia | El mapa es ficción de sala de conferencias — sin fuentes de datos citadas, puntos de fricción inventados | Se nombran algunas fuentes pero los puntos de fricción no se trazan a ellas; secciones asumidas no se distinguen de las investigadas | Las fuentes se enumeran en el encabezado, los puntos de fricción clave se vinculan a datos específicos (categorías de tickets, % de encuesta, citas de entrevistas), etapas asumidas etiquetadas y una tabla de brechas de investigación cubriendo las afirmaciones en las que se apoyan las recomendaciones |
| Veracidad emocional | Sin capa emocional — un flujo de procesos con la ropa de un mapa de recorrido | Las emociones se enumeran por etapa pero la curva es aspiracionalmente suave; el punto más bajo sin nombre o suavizado | Emoción en cada etapa, una curva con un punto bajo real, y el punto más bajo / caída más grande nombrado con evidencia — incluyendo dolor del cliente que entra en conflicto con una métrica de un equipo interno |
| Viabilidad de oportunidades | Oportunidades faltantes, sin clasificar, o lugares comunes ("mejorar la incorporación") | Las oportunidades se enumeran pero son vagas, o se clasifican sin razonamiento de impacto/esfuerzo; no ponderadas hacia la fricción más alta | Cada oportunidad escrita como elemento de backlog listo, clasificado por impacto y esfuerzo, con P1s dirigidos al momento de fricción más alta que la curva identificó |

## Listas de Verificación de Calidad

- [ ] El mapa cubre una persona específica — no "todos los clientes"
- [ ] Cada etapa incluye el estado emocional del cliente — no solo acciones
- [ ] Los puntos de fricción son el dolor del cliente — no el dolor de la empresa
- [ ] Las oportunidades son específicas suficientes para convertirse en elementos de backlog o indicaciones de diseño
- [ ] La curva de emociones muestra la experiencia real — no una versión aspiracionalmente positiva
- [ ] Las brechas de investigación están documentadas — el mapa refleja lo que se sabe, no lo asumido

## Antipatrones

- [ ] No construyas el mapa solo a partir de suposiciones — ancla al menos los puntos de fricción en datos de clientes reales o investigación
- [ ] No trates todas las etapas del recorrido como igualmente ponderadas — identifica explícitamente los momentos de mayor fricción
- [ ] No omitas la capa emocional — un mapa de recorrido sin emociones es un flujo de procesos, no un mapa de cliente
- [ ] No crees puntos de contacto genéricos que se apliquen a cualquier producto — cada punto de contacto debe ser específico para este producto y cliente
- [ ] No dejes oportunidades sin clasificar — prioriza por impacto y viabilidad
